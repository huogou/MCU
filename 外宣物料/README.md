## 核心原则

1. **真实产品优先**：所有宣传图必须以最终真实 PC 页面截图为核心素材，不重新虚构宇宙地图。
2. **外围可加工**：标题排版、背景处理、装饰、构图、CTA 可在外围加工，但不修改真实产品 UI。
3. **平台差异化**：抖音、小红书、快手各有不同的标题口径和 CTA 引导，按各自规范执行。

## 制作流程

1. 打开 `h5/map-pc.html`，在 1920×1080 分辨率下操作页面。
2. 按素材规范截图（全景 / 局部 / 交互状态）。
3. 将截图存入 `PC截图/` 目录。
4. 按平台构图规范，在截图外围添加标题、副标题、CTA、装饰。
5. 将最终封面存入 `封面/` 目录。
6. 不修改任何真实产品 UI 元素。
