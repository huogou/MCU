# PC 地图宣传素材规范

> 本文件定义四类外宣素材的截取与制作规范。所有素材以真实 PC 端 `map-pc.html` 页面为基础。

---

## 一、素材 A｜PC 地图全景

### 截取要求

- **分辨率**：1920×1080（或 2K/4K 高清截取后缩放）
- **页面状态**：默认全览视图（点击「重置」按钮后的初始状态）
- **内容**：完整展示 MCU 宇宙地图——所有阶段背景列、主线轨道、节点、关系连线、时间轴
- **操作**：
  1. 浏览器全屏模式（F11 或点击页面右上「全屏」按钮）
  2. 点击「重置」按钮回到初始视图
  3. 确保所有节点和连线可见
  4. 截取整个浏览器窗口

### 用途

- 官网页面头图
- H5 分享卡片
- 产品介绍文档配图
- 各平台宣传文章正文配图

### 注意

- 不要在筛选状态下截取（必须展示全部内容）
- 确保顶部导航和时间轴完整出现在截图中
- 截图时不要有 hover 高亮状态

## 二、素材 B｜地图局部特写

### 截取要求

- **分辨率**：1920×1080
- **选取区域**：最具视觉表现力的区域，推荐以下区域：

| 区域 | 年份范围 | 包含节点示例 | 视觉特点 |
|------|----------|-------------|----------|
| 无限传奇收束 | 2016-2019 | 内战→奇异博士→诸神黄昏→无限战争→终局之战 | 主线汇聚、连线密集 |
| 多元宇宙开启 | 2021-2022 | 英雄无归→疯狂多元宇宙 + 剧集节点 | 跨类型连线、多元宇宙关系 |
| 第一阶段组队 | 2008-2012 | 钢铁侠→雷神→美队→复仇者联盟 + 短片 | 起点感、星散到汇聚 |

### 操作

1. 放大到 150%-200% 缩放级别
2. 拖动地图到目标区域
3. 确保截图中包含：3-5 个核心节点 + 2-3 条关系连线 + 底部时间轴局部
4. 截取

### 用途

- 抖音 / 小红书 / 快手 宣传帖主图
- 短视频封面
- 朋友圈宣传图

### 注意

- 选择连线密集、节点关系清晰的区域
- 确保节点上的海报图片和文字标签清晰可读
- 尽量包含不同类型的节点（电影 + 剧集）

## 三、素材 C｜交互状态

### 截取要求

- **分辨率**：1920×1080
- **状态**：一个作品被选中 → 当前节点突出 → 关联节点和关系线高亮 → 无关节点弱化

### 推荐选中节点

| 选中作品 | 原因 | 关联展示效果 |
|----------|------|-------------|
| 复仇者联盟 | 向前关联钢铁侠/雷神/美队，向后关联冬兵/奥创 | 辐射状高亮，最直观 |
| 无限战争 | 前接内战/诸神黄昏/银护，后接终局之战 | 密集连线，关系最复杂 |
| 英雄无归 | 前接英雄远征，后接疯狂多元宇宙/崭新之日 | 跨阶段关系清晰 |

### 操作

1. 放大到 120%-150%
2. 点击目标节点，等待高亮动画完成
3. 确保详情弹窗出现在截图中
4. 截取

### 用途

- 说明「这个地图可以探索作品关系」
- 产品功能演示图
- 教程类宣传素材

### 注意

- 详情弹窗应完整出现在截图中
- 高亮的连线和节点要清晰可见
- 被弱化的节点不能完全看不见（保持 0.1-0.2 透明度）

## 四、素材 D｜宣传封面构图规范

### 通用规范

- **核心素材**：真实 PC 页面截图（素材 A/B/C 均可）
- **外围可加工**：标题、副标题、CTA、背景、装饰、构图
- **禁止**：修改真实产品 UI（不改变节点位置、不增删连线、不改文字）

### 构图模板

```
┌──────────────────────────────────────┐
│                                      │
│  [背景处理：深色宇宙渐变 + 星点]        │
│                                      │
│  ┌────────────────────────────────┐  │
│  │                                │  │
│  │    [真实 PC 页面截图]           │  │
│  │    （居中或偏一侧放置）          │  │
│  │                                │  │
│  └────────────────────────────────┘  │
│                                      │
│  [大标题]                             │
│  [副标题]                             │
│  [CTA 按钮或文字]                     │
│                                      │
└──────────────────────────────────────┘
```

### 标题排版规范

- **字体**：思源黑体 / 苹方 / 微软雅黑（粗体）
- **大标题字号**：占封面宽度 60-80%
- **副标题字号**：大标题的 40-50%
- **CTA 字号**：副标题的 80-100%
- **颜色**：
  - 大标题：白色 #FFFFFF 或金色 #F2B233
  - 副标题：浅灰 #8E98AA
  - CTA：金色 #F2B233（带深色底色按钮）

### 背景处理规范

- 基色：#050810（与页面背景一致）
- 渐变方向：从中心向外暗化
- 可追加：星点（白色 0.1-0.3 透明度）、光晕（金色/蓝色 0.05-0.1 透明度）
- 不可追加：与产品 UI 冲突的霓虹色、赛博朋克纹理

### 装饰元素

- 允许：细线分隔、小图标、阶段色色块
- 禁止：复杂 3D 元素、大量贴纸、与 MCU 无关的装饰
