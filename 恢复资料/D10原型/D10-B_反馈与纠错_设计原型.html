设计说明

Token 继承：所有颜色、圆角、字体、间距严格继承 app.wxss 现有 Token 系统。

入口设计：「我的 MCU」底部轻量入口 + 电影详情内容区底部纠错入口，均不抢占核心 CTA。

反馈对象：从电影详情进入时自动携带 movieId，显示为只读标签；从「我的 MCU」进入时不强制选择。

类型选择：6 种类型双列卡片布局，单选，选中态用金色边框 + 金色勾选标识。

表单极简：仅「类型 + 详细说明」两个必填项，无姓名/手机/邮箱等个人信息。

提交校验：未填详细说明时按钮禁用 + 红色提示文案。

成功态：居中绿色勾选图标 + 感谢文案 + 返回按钮，无复杂反馈编号/进度追踪。

异常态：网络失败时提示「内容已本地保存」+ 重新提交按钮。
