## 5. 存储设计

- 键：`mcu-xhs-progress-v1`；结构：
  ```js
  { version: 1, watched: { "key": "ISO 时间" }, want: ["contentId"], updatedAt: "ISO 时间" }
  ```
- 节点键：普通作品用 `contentId`；专题分季用 `contentId|季标签`（如 `loki|洛基 S1`）。
- 读取顺序：`xhs.miniTool` Storage（客户端 ≥9.46）→ `localStorage` → 内存。
- 容错：JSON 损坏、字段类型异常、读写失败均回退，不阻塞 UI。
- 清除：仅依赖已核实的 `setStorage({key, data:''})`，不假设存在 `removeStorage`。
- 隐私：不要求登录、不上传个人数据；数据仅存本机。

- 可访问性：按钮具 `aria-label`，`prefers-reduced-motion` 关闭过渡。

## 11. 官方文档与 API 核对

2026-11-10 通过在线文档核对并落地：

- `window.xhs.launchOptions.miniToolEnv.buildVersion`，缺失时异步 `getLaunchOptions()`。
- `buildVersion` 末 3 位为编译号；客户端版本 = `Math.floor(buildVersion / 1000)`。
- Storage 需客户端 ≥9.46.0；`setStorage({key,data})`、`getStorage({key}) → {data}`。
- `saveImageToPhotosAlbum` 需 ≥9.42.0。
- `postNote` 使用 `pageType:'photo_publish'`、`mediaInfo.image_resources[].url` 为本地 `filePath`。
