## 1. 一页结论（5 条内）

1. **V3.0 定位升级为「漫威综合助手」**：在 V2.0（F1–F4 探索工具 + F5 进度 + F6 复联5专题）基础上，新增「互动系统」，形成探索 / 观影 / 互动三大方向并重的四层架构；这是产品定义的扩展，非推翻重做。
2. **架构底座已具备 70% 复用条件**：V2.0 的 7 视图 SPA、离线数据管线（`build-data.js`→`data.js`）、`MCUProgress` 存储模块（含 xhs/localStorage/memory 三级降级与 `version` 迁移字段）均可直接作为 V3.0 基座。
3. **两块关键数据缺口必须前置立项**：①「英雄关系网络」所需的人物↔人物关系边在 `h5/data/characters.js` 中明确为 TODO（仅有作品共演可推导，无显式 why）；②「知识问答」所需题库在当前任何数据源中均不存在。两者不上线数据，相关模块无法交付。
4. **平台硬约束未变且不可突破**：纯离线（禁 fetch/XHR）、单 key ≤1MB / 总 ≤10MB、ZIP ≤10MiB、禁服务端/付费 API、禁小工具间通信。V3.0 统一用户状态 `MCU_USER` 必须压在 1MB 单键内。
5. **本文件为规划稿，存在 1 处状态冲突与 6 处待确认项**（详见 §8），需 ChatGPT 审查裁定后方可进入开发。

## 4. V3.0 产品架构（四层）

### 4.1 首页控制台（Home Console）
- 在 V2.0 静态 6 入口基础上，改为**状态驱动动态首页**：品牌展示、今日探索推荐（基于 `recentExplore` 与随机兜底）、我的观影进度（复用 F5 统计）、最近探索记录（读 `MCU_USER.recentExplore`）、继续上次观影路线（读 `MCU_USER.currentRoute`）、探索/观影/互动三大区入口。
- 不新增独立页面，复用现有 7 视图 SPA，新增「互动」入口与首页动态渲染逻辑。

### 4.2 探索系统（Explore）
- 角色探索（F2 增强：角色详情、关联作品、阵营）；英雄关系网络（**数据缺口见 §8③**，先以作品共演推导弱关系，待人物关系边补齐后升级为显式关系）；MCU 宇宙时间线（基于 `CONTENT.co` 故事时间线视图）；作品搜索与资料查询（F2 检索增强）；随机探索（F3 继承）。

### 4.3 观影系统（Viewing）
- 上映顺序（F1 release）、时间顺序（F1 chrono）、主线精选（F1 mainline）、观影进度管理（F5 继承扩展）、个性化观影路线（基于 `watched`+路线生成）、复联5补课专题（F6 继承）、下一部作品推荐（基于 `watched` 与未看路线推导）。
- 全部复用 `MCU_CONTENT` + `MCU_ROUTES` + `MCU_SPECIAL_ROUTES`，与 H5 数据母库通过 `build-data.js` 同源构建。

### 4.4 互动系统（Interact）
- 漫威知识问答（**需新建离线题库，见 §8④**）、英雄组队器（基于 `MCU_CAMPS` 8 阵营 + 角色 camp 字段）、观影挑战（由路线/进度推导）、成就系统（由进度/挑战/问答派生，规则离线定义）、个人漫威档案（由 `MCU_USER` 全量派生）、分享卡片升级（F4 扩展：成就卡/档案卡/组队卡/挑战卡）。
- 互动结果必须回写 `MCU_USER` 并关联角色/作品/进度/成就，避免成为互不相关的小游戏。

## 5. 统一用户状态与数据架构（纲要）

- 设计统一 `MCU_USER` 数据模型（详见交付物③），存储键建议 `mcu-xhs-user-v2`，带 `version:2`，由 V2.0 的 `mcu-xhs-progress-v1` 迁移而来。
- **三系统共享机制**：单一 `MCUUser` 存储模块（沿用 `MCUProgress` 的 subscribe/emit 订阅模式），所有视图只读/写该模块，不各自持有用户数据副本；作品/角色/关系等**内容数据**单一来源为 `data.js`（只读，构建期注入），杜绝双份维护。
- **版本升级**：`version` 字段驱动迁移函数（v1→v2）；损坏数据回退空态（沿用 F5 `parse` 容错）。
- **存储异常与恢复**：三级后端探测（xhs≥9.46 / localStorage / memory）+ 写失败降级保留当次操作（沿用 F5）。
- **V2.0 兼容**：读取旧键 `mcu-xhs-progress-v1` → 映射 watched/want → 写入 v2；迁移后可清理旧键。
- **容量硬约束**：单 key ≤1MB；`recentExplore`(≤20)、`shareRecords`(≤50)、`quiz.scores`(封顶) 均设上限，保证 `MCU_USER` 不超 1MB。

## 6. 三条完整功能联动路径（纲要，详见交付物④）

- **路径 A 英雄探索→观影计划**：搜钢铁侠 → 看相关角色/关联作品 → 加入想看/路线 → 标记已看回写进度。
- **路径 B 观影计划→互动挑战**：选复联5补课路线 → 看待看作品 → 标记已看更新进度 → 触发知识问答 → 记录成就。
- **路径 C 知识问答→角色探索**：参加问答 → 看答题涉及的角色/作品 → 进详情 → 加入观影计划。
- 每条路径均在交付物④中以「流程图 + 逐步读取/写入数据表」呈现。
