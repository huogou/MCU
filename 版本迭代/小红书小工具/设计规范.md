## 1. 设计原则

- **复用母项目视觉语言**：与 MCU Atlas 品牌一致，降低跨端认知成本。
- **小红书适配**：卡片与界面需符合小红书图文审美（高饱和度点缀、留白、情绪化标题）。
- **轻量优先**：小工具形态，信息密度克制，单屏聚焦一个动作。
- **平台可落地**：所有视觉须可由 HTML/CSS 与 **Canvas 2D** 实现（容器禁 WASM/Worker，重计算不可行）。

## 3. 分享卡片规范（F4 · 已澄清 D-20260928-04）

### 3.1 输出机制
客户端 **Canvas 2D** 渲染卡片位图 → `writeTempFile`（base64→filePath）→ `saveImageToPhotosAlbum`（存相册）或 `postNote`（发笔记）。

### 3.2 硬约束（来自官方端能力）
- **卡片标题 ≤ 20 字**（`postNote.title` 上限，硬性锁定）。
- 笔记正文 ≤ 1000 字；图片 1–18 张；媒体字段不接受 `http(s)://`（仅 `data:` base64 或本地路径）。
- 设计 AI 提供的卡片布局须是**可程序化渲染**的规格：明确图层、坐标、字号、颜色、主图占位，而非仅一张静态样图。

### 3.3 建议参数（待阶段3 设计 AI 在小红书审美下确认）
- 建议比例：3:4（小红书图文主流竖版）。
- 必备元素：标题、一句话看点、视觉主图/节点图、品牌署名「漫威宇宙导航」。

## 4. 平台视觉落地约束（D-20260928-05）

- **脚本必须外置**：设计交付的 JS / 交互逻辑须为包内 `.js` 文件（`<script src>` 引入），不能用内联 `<script>` 或 `onclick=`。样式 `<style>` / `style=""` 可内联。
- **资源全打包**：图片 / 字体须随包内置（白名单 png/jpg/jpeg/gif/webp/svg、woff/woff2），无 CDN。
- **Canvas 为主**：卡片与图表优先 Canvas 2D 渲染；WebGL 仅用于纯本地纹理渲染。

## 7. V2.0 实际落地规格（2026-11-10）

### 7.1 页面结构
- 首页 2×2 主入口 + 两个横向入口：「我的观影进度」「复联5补课专题」。
- 进度页：大号百分比 + 三段统计（已看 / 待看 / 想看）+ 复联5两条路线进度条 + 想看/已看列表 + 生成进度卡 + 清除（二次确认）。
- 专题页：标题、官方档期、「核心 8 部 / 完整 15 部」切换、逐条补课理由与已看开关、五段说明、底部两张清单卡入口。

### 7.2 组件状态
- 已看：`✓ 已看` 按钮高亮（`#4CD1A5`），条目显示「已看」徽标。
- 想看：`✓ 想看` 按钮高亮；已看作品不可加入想看。
- 空态：进度页与卡片均有「还没有标记已看作品」等明确文案，不显示空白区块。
- 全局提示：轻提示浮层 `globalTip`，用于已看/想看冲突说明。
- 减少动效：`prefers-reduced-motion` 下关闭过渡。

### 7.3 Canvas 卡片（900×1200）
| 类型 | 内容 | 排版要点 |
|---|---|---|
| `custom` | 标题 / 一句话看点 / 品牌 | 标题最多 2 行，副标题 1 行省略 |
| `progress` | 大号百分比、已看/待看/想看、已看 4 条、想看 3 条 | 超出条数显示「…以及另外 N 部」；空态两行引导文案 |
| `a5core` | 8 部核心清单、进度 1/8、档期、边界声明 | 已看项绿色勾选；底部标注「仅含官方档期信息，不含剧情推测」 |
| `a5full` | 15 部完整清单、进度 1/15 | 最多展示 12 条 + 「…以及另外 3 部」 |

- 文本统一走 `layoutLines()` 折行：仅在实际超宽时补省略号，短文本不截断。
- 边距 60px、内容宽度 780px；底部品牌区固定，不与正文重叠。

### 7.4 响应式
- 360–430px 主流宽度：卡片类型按钮改为换行排列，避免出现横向滚动条。
- 列表按钮最小点击高度 36px；长标题自动换行，不溢出容器。
