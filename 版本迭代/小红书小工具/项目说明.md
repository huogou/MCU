## 1. 基础定义

- **项目名称**：MCU Atlas × 小红书小工具 V1
- **产品名称**：漫威宇宙导航
- **载体形态（已澄清 D-20260928-02）**：小红书小工具容器——运行在小红书 App 沙箱内的纯本地 Web 应用（HTML / CSS / JS），平台自动注入端能力 SDK（`window.xhs.miniTool`）。
- **定位**：基于 MCU Atlas 数据体系打造的小红书**离线**漫威探索工具。
  - 「离线」= 平台强制的纯本地运行、不联网、资源全打包（已澄清 D-20260928-03，非产品臆测）。
- **母项目**：MCU Atlas（H5 `mcuatlas.xyz` + 微信小程序 `wx78f00e7f0a5948b7`）
  - 数据单一可信源：`h5/data/*.js`（`MCU_CONTENT` 59 部 / `routes` 11 条 / `relations` 92 条）

## 2. 核心功能

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 漫威观影顺序 | 按官方 / 时间线 / 自定义维度输出 MCU 推荐观影顺序 |
| F2 | 宇宙节点探索 | 以节点（角色 / 事件 / 阶段）为单位浏览宇宙关系 |
| F3 | 随机漫威探索 | 随机推荐一部作品 / 一个角色，降低决策成本 |
| F4 | 生成漫威分享卡片 | 客户端 Canvas 渲染卡片 → 存相册 / 发笔记（已澄清 D-20260928-04） |

## 3. 范围与边界

### 在范围内（In Scope）
- 复用母项目 MCU Atlas 数据体系，不新建主数据。
- 围绕 F1–F4 四项核心功能的最小可用形态（小红书小工具载体）。
- 适配小红书小工具平台的视觉与卡片输出（Canvas 渲染）。

### 不在范围内（Out of Scope，V1）
- **无任何后端 / 服务端**（平台强制不联网，非产品选择）。
- 不做用户账号体系、不做社区 / UGC / 资讯流。
- 不替代 H5 / 微信小程序，独立载体互补。

## 4. 平台硬约束摘要（详见数据方案 §3 / 决策记录 D-20260928-05）

- 纯本地运行、不联网：所有资源必须打包内置。
- 脚本必须外置（`<script src>`），禁内联 / 禁 `eval` / WASM / Worker / iframe。
- 端能力：`postNote` / `saveImageToPhotosAlbum` / `writeTempFile`（F4 依赖）。
- 包体积上限：官方指南本次未给明确 MB 数，阶段6 前核实。

## 5. 协作与治理

- 三 AI 隔离：策划（GPT/deepseek）→ 设计（QoderWork CN）→ 开发（CodeBuddy），通过本目录文档协作。
- 开发 AI 不自主设计与拍板；产品定义变更须经决策记录留痕。
