## 一、这是什么

- **项目名称**：MCU Atlas × 小红书小工具 V2.0
- **产品名称**：漫威宇宙导航
- **载体形态（已澄清 D-20260928-02）**：小红书小工具容器——运行在小红书 App 沙箱内的**纯本地 Web 应用（HTML / CSS / JS）**，由平台注入端能力 SDK。不是小程序、不是 H5 外链。
- **定位**：基于 MCU Atlas 数据体系打造的小红书**离线**（平台强制纯本地运行、不联网）漫威探索工具。
- **母项目**：MCU Atlas（H5 `mcuatlas.xyz` + 微信小程序 `wx78f00e7f0a5948b7`），数据单一可信源 `h5/data/*.js`。
- **平台权威文档**：小红书《小工具容器能力清单》（2026-08-11）。
