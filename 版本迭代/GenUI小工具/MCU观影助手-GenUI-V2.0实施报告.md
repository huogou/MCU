## 二、核心结论

1. **数据层**：三条路线 38 个渲染实例（12 + 18 + 8）全部具备 `badge / reason / role / gains(2) / next`；去重作品 24 个（洛基 S1、S2 分列），去重母项目 id 23 个（洛基两季共用 `loki`）。徽章分布 **必看 34 + 推荐 4**，与 §7.2「新手 11+1 / 主线 18 / 补课 5+3」完全一致，「补充」级本轮不出现（数据事实）。
2. **长度断言（新增构建门）**：字段超预算即 `exit 1`，UI 无 truncate 兜底。最终实测最大可见宽度：reason 36/36、role 53/54、next 34/36、gains 26.5/36、intro 四项 51/54、37/39、36/36、34.5/36 —— **全过，且 UI 零省略号**。
3. **版式实测（360/414，浏览器真测而非估算）**：内容区 227/281 精确命中；360 档字段内容 156 + 页头 36 + 页码条 26 = 218 ≤ 227（余 9px）；414 档余 63px。**V2.0-R4 起余量不再沉底**：字段区 `justify-content:space-between` + `gap:4px`（min），实测 4 段间距 **360 档 7–16.3px、414 档 25–38.3px**，上下贴合（topPad/bottomPad ≤1px），**零横向溢出、零纵向滚动、零裁切**。
   （口径说明：设计稿 §5.2 的 mock 实测区间为 360 档 6–16px、414 档 24–34px；本实现 414 档最大 38.3px 出现在「终局之战」页——该页 414 下字段只占 104px 自然高，按「行数越少间距越大」的弹性规则摊得更大，硬约束（≥4px、铺满、不裁切）均满足。）
4. **交互**：滑动（pointer 判定 24px / 1.5 倍方向锁定）、◀▶ 翻页、300ms busy 锁、首末页禁用 no-op、切路线页码重置、重置回 1/13 —— 全部通过；**画布内滑动不触发路线切换**（事件隔离 + `touch-action:none` 双保险）。进度条 = (k−1)/N（0% / 8.3% / 100% 实测）、kicker `ITEM k/N` 与页码一致。
5. **守卫**：`guard-frozen` 全绿（外壳样式零改动、7 项结构存在性、3 项 token 纪律、12 项硬指标），5 个函数名原样保留。
6. **控制台**：产物零 JS 报错（预览 harness 自身注入的 cosmic css / 统计脚本噪声已过滤并计数）。
