## 第 3 轮 · 重写画布渲染（授权单 §四-5）

**类名**（照抄 §9，旧 `.mcu-order-*` 整组删除）：`.mcu-route-canvas`（token 作用域 + `overflow:hidden`）、`.mcu-page-track`、`.mcu-page`、`.mcu-page-head/-kicker/-title`、`.mcu-badge(-core/-recommended/-optional)`、`.mcu-series-tag`、`.mcu-field-row/-label/-body`、`.mcu-block-row/-label/-body`、`.mcu-pager/-btn/-prev/-next/-num`、`.mcu-pager-track/-progress`；跳转浮层 `.mcu-jump-*` **未实现**（§8.3 条件功能，默认不启用）。

**颜色**：`--mcu-*` 全部声明在 `.mcu-route-canvas`（`--mcu-bg #080B12`、`--mcu-gold #F2B233`、`--mcu-p1…p6` 等 17 个），未定义任何 `--cos-*`。

**交互**（§8）：
- 滑动：Pointer Events（`pointerdown` 累计 → `pointerup` 判定），阈值 `|Δx| ≥ 24 且 |Δx| ≥ 1.5|Δy|`；`touch-action:none` 只挂轨道；降级 touch 事件
- 翻页：`translateX` + `transition 200ms ease-out`；翻页后 300ms busy 锁（按钮与滑动共用）
- 边界：首/末页按钮 `opacity .25 + aria-disabled=true + 事件 guard 返回`，点击与滑动均 no-op
- 进度条：`.mcu-pager-progress` 宽度 = (k−1)/N，介绍页 0%、末页 100%
- 无障碍：轨道 `role=region` + `aria-label`、`tabindex=-1`；页码容器外挂 `.mcu-sr-only[aria-live=polite]` 播报「第 k 页，共 N 页」
- 打点：`sendLog('operation')`（切路线/重置）、`sendLog('page')`（翻页/滑动）

**保留**：`onTabChange / resetDemo / sendLog / showTipsTooltip / adjustTipsTooltipPosition` 函数名与外壳 HTML/CSS 一字未改。
