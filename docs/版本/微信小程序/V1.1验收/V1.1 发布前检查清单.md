## 二、发布操作步骤（用户在微信开发者工具手动，需扫码）

1. 打开项目 `mcu-miniprogram`
2. 点「上传」→ 版本号填 `v1.1.0`
3. 备注：`V1.1 首页继续观看 / 我的MCU 2.0 / 分享海报 / 成就系统 / 角色主页 / D12 视觉统一`
4. 登录 `mp.weixin.qq.com` → 版本管理 → 开发版本 → 提交审核
5. 审核类目/标签沿用既有填写
6. 审核通过 → 全量或灰度发布

## 三、风险与回滚

- **回滚**：线上保留 v1.0.x，审核不通过可撤回开发版本，不影响现网
- **审核周期**：1–7 天，留意微信服务通知
- **后台依赖**：无新增；feedback 匿名写入已就绪（CloudBase NoSQL）
- **代理注意**：若上传走 tcb/CLI 报 ECONNREFUSED，先 `unset HTTP_PROXY HTTPS_PROXY` 再操作
