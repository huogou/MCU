三、CDN / 加载失败 / 弱网
============================================================
3.1 CDN 资源
  [通过] 图片资源全部托管于自有 CloudBase 静态托管，无第三方盗链、无外部图床、无外链风险。
  [阻断项-需人工] 微信生产环境要求 <image> 远程域名加入「downloadFile 合法域名」。
        → 必须在 mp.weixin.qq.com 后台「开发管理 - 开发设置 - 服务器域名 - downloadFile 合法域名」添加：
          https://mcu-d6gw0brqoa9521b58-1307093647.tcloudbaseapp.com
        说明：project.config.json 中 urlCheck:false 仅对开发者工具本地生效，生产环境不豁免，
              未配置将导致真机图片全部加载失败。

3.2 图片加载失败处理
  [通过] 关键页面（panorama / home / character / explore / movie / characters）均使用 binderror 兜底：
        onImgError / onPosterError 置 _imgErr[id]=true → 隐藏 <image> 并显示
        「阶段色渐变 + 首字占位」。设计上不出现裂图。

3.3 弱网环境表现
  [说明] 弱网下：占位卡（阶段色 + 首字）即时渲染，文本 / 结构本地加载，
        核心浏览（顺序 / 路线 / 关系）不依赖网络，仅海报 / 头像需 CDN。
  [建议] 当前无本地图片缓存策略，重复进入会重复请求 CDN；非阻塞，可留待 V1.3 评估。
