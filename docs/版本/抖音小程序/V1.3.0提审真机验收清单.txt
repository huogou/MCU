B. 必须由人工在 IDE / 真机完成的 7 项
═══════════════════════════════════════════════════════════

□ B1. TabBar 三项
     预期：首页｜作品｜我的MCU 依次排列
     检查：图标显示清晰（非空白）、选中态变金色、点击切换无卡顿、
           三个页面均无白屏、控制台无报错
     备注：图标文件本身已通过门禁（81x81 / 非空白 / 两态异色 / 跨 Tab 无色差）

□ B2. 作品查询页实操作
     路径：首页 → 点「作品查询」入口卡 → 进入 Tab2
     逐项：搜索中文（例：钢铁侠）／搜索英文（例：iron）／类型切换（电影·剧集·
           特别呈现·短片）／阶段切换（P1-P6）／已看·未看切换／排序切换
           （上映顺序 ↔ 故事时间线）／点「重置」／点列表项进详情
     预期：每次筛选后「共 N 部」即时变化，结果可点开详情

□ B3. 作品详情页（至少打开 3 部，建议含：钢铁侠 / 复仇者联盟 / 旺达幻视）
     逐项核对顶部信息表 9 行是否齐全：
       内容类型｜上映日期/上线日期｜MCU 阶段｜所属篇章｜篇幅｜上映顺序｜故事时间
     以及：海报、中英文名、作品简介、我的观看状态、两个操作按钮、相关作品列表

□ B4. 已看状态联动（端到端）
     操作：详情页 → 标记为已看
     核对四处：
       □ 我的MCU：已看数 +1、未看数 -1、已看列表出现该作品
       □ 作品查询：「已看」筛选能查到，「未看」筛选不再含它
       □ 首页：进度百分比变化（例 1/59 → 2%）
     再操作：取消已看 → 以上四处全部反向恢复

□ B5. 收藏状态联动（端到端）
     操作：详情页 → 收藏这部作品
     核对：□ 按钮变「取消收藏」
           □ 我的MCU 收藏计数 +1
           □ 我的作品清单 → 收藏 列表出现该作品
           □ 作品查询列表该项出现 ★ 标记
     再操作：取消收藏（详情页或列表内 ★ 均可）→ 全部恢复

□ B6. 冷启动持久化
     操作：先完成「标记已看 2 部 + 收藏 1 部」
           → 关闭/划掉小程序进程 → 重新进入
     预期：已看数、收藏数、列表内容与退出前完全一致

□ B7. Canvas 海报 + 相册保存
     路径：我的MCU → 分享我的 MCU 进度
     检查：□ 海报正常渲染（背景/进度条/片单信息/最近观看海报全部可见）
           □ 点保存 → 成功写入相册 → 提示「已保存到相册」
           □ 首次拒绝相册授权 → 弹出权限引导 → 去设置开启后可再次成功
     ⚠ 若任一项异常，先修复再提审，不要跳过
