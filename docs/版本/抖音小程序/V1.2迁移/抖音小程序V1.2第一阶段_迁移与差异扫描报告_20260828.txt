八、【6】可能影响用户体验的地方
----------------------------------------------------------------
- 分享目标差异：抖音「转发给朋友」走抖音分享面板（抖音好友 / 私信 / 动态），不再发到微信；海报「保存到相册」仍可正常使用。
- 相册授权文案：scope.writePhotosAlbum 抖音同名，但隐私文案现写「微信」会令用户困惑（见【2】乙）。
- Canvas 渲染表现：explore 关系网络图、panorama 全景图、share 海报均依赖 Canvas 2D，抖音渲染引擎与微信存在差异，需真机确认清晰度 / 性能（R1–R5）。
- 暗色导航栏：window.navigationBarTextStyle=white + 深色背景在抖音端表现需真机核对。

----------------------------------------------------------------
九、【7】可能影响审核的地方
----------------------------------------------------------------
- 隐私政策与事实一致性（高优先级）：privacy.wxml 现写「微信本地存储 / 微信相册权限 / 微信中管理」，与抖音实际不符。抖音审核要求隐私政策如实描述，建议上线前修正（见【2】乙）。
- 应用名称商标：微信版名「MCU观影导航 / 漫威电影宇宙导航」含 Marvel「漫威 / MCU」商标词，抖音审核同样存在驳回风险；备选名建议沿用微信版结论（如「观影顺序导航」等），需策划确认。
- 包体整洁度：根目录下存在 漫威电影导航/（空白模板残留）与 __MACOSX/（macOS 元数据），虽不影响运行，提交审核包建议清理，避免审核侧疑问。
- 无其余违规内容：内容为电影观影顺序指南（工具-信息查询类），无 UGC / 支付 / 隐私采集。
