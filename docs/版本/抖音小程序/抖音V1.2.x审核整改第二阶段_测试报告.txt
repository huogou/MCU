一、驳回原因复盘（根因判定）
═══════════════════════════════════════════════════════════

驳回原文：
  「小程序功能不完整且可用性低，请丰富小程序内容和功能，提高用户体验」

客观事实：
  上一轮（2026-09-07）按「文娱-资讯」类目要求做减法，一次性删除了
  explore / panorama / characters / character / routes / route-detail / movie
  共 7 个页面，但没有留下任何替代能力。

减法的副作用（可验证的现状）：
  1. 全应用可跳转目标仅剩 4 个：share / feedback / agreement / privacy /
     about（my-mcu 内部三个列表均无可点击绑定）
  2. 「我的MCU」的「观看记录」「收藏」两段列表为纯展示<view>，点击无响应
  3. userState.toggleFav() 在数据层已实现，但全应用无任何调用入口
  4. 首页可操作控件只有 2 个：「标记为已看」按钮 + 跳 Tab
  5. 无搜索、无筛选、无列表页、无详情页

结论：
  审核员的「功能不完整且可用性低」是对上述事实的准确描述，不是误判。
  本轮整改的正确方向是「补回可用性」而非「继续做减法」，
  即在「工具-实用工具-信息查询」类目下增加真实的查询与管理能力。

四、审核风险检查
═══════════════════════════════════════════════════════════

1. 文娱资讯风险
   扫描范围：pages/ models/ app.js app.json
   禁用词：官方 / 正版 / 授权 / 资讯 / 新闻 / 热点 / 影评 / 独家 /
           首播 / 最新消息 / 票房 / 媒体报道
   结果：命中 9 处，**全部位于开发注释**，无任何用户可见文案命中。
   结论：无此风险。

2. 官方授权暗示
   · 用户界面无任何「官方」「正版」「授权」字样
   · 关于页已自带免责表述：
     「本小程序为个人非商业工具，仅提供观影记录与进度管理服务，
       影视资料均来自公开信息整理。」
   · 数据层的 source / src 字段含「Marvel 官方 Complete MCU Timeline」
     字样（数据来源标注），但**未在任何页面渲染**，不构成暗示。
   结论：无此风险。

3. 页面内容违规风险
   · 未恢复任何资讯型页面
   · 详情页主动规避了 role 字段（剧情作用解读类编辑文本），
     仅保留 sf（无剧透简介）
   · 不含推荐文章 / 热点榜 / 票房榜 / 演员资讯 / 影评入口
   结论：无此风险。

4. 唯一残留项（低危，需产品决策）
   relations.js 第 61 条 why 文本含「失去官方支持」四字，
   会出现在《奥创纪元》详情页的「相关作品」一栏。
   语义为剧情内表述（指片中政府机构的支持），非授权声明。
   如需彻底清零，可对该条做文案微调，但会触碰数据文件，
   涉及「禁止修改数据的纪律」，故本轮未动，交由产品决策。
