## 一、裁定结论（逐项）

### 1. 内容区留白（L1）→ **采纳方案 B（字段纵向均分铺满）**

- 口径：字段/介绍块间距由固定 `4px × 3` 改为**弹性（min 4px）**，字段区 `justify-content: space-between` 纵向铺满；页码条仍贴底（flex none 不动）。
- 依据：产品侧诉求"把内容区利用起来"；360 真机档几乎零变化（余量 9px 摊 3 处 → 间距约 7px）；不触碰任何硬约束（字号 12px/16px、行数 2/3/2/2、零滚动、零截断均不变）；方案 C 只居中不利用、方案 D 违反字号固定、方案 E 超授权范围需新规格。
- 规格修订位置：设计稿 §5.2 合计行、§5.3/§5.4 gap 行、§14 账单 ⑯、mock CSS（已同步）。
- **开发执行**：改 `.mcu-page-fields` / 介绍页 `.mcu-page-blocks` 为 `justify-content: space-between` + `gap: 4px`（gap 为 min 值）；同步 e2e 新增断言「字段区间距 ≥4px 且字段区纵向占满」；360 档实测间距应约 7px、414 档约 25px，记录到实施日志。

### 2. 宽容器（>414）→ **不纳入验收档**

- 口径：真机目标为手机视口（360–430），验收保持 **360 / 414 双档**；宽容器按 1:1 等比放大、以方案 B 口径自然铺满，**不做额外承诺、不作为驳回依据**；e2e **不新增**宽容器正式断言套件（避免对未定义档位做承诺）。
- 规格修订位置：设计稿 §14 账单 ⑰。

### 3. 文案压缩（L2）→ **A2–A6 追认；A1 需调整（保留"跨宇宙角色"）**

- 追认：A2（补课"怎么排"7 环节全保留仅压缩措辞）、A3（黑豹"为什么看它"删"故事"）、A4（奇异2"后续关联"删冗余）、A5（洛基 S1"为什么看它"删时间前跳背景句，kw+核心因果保留）、A6（主线精选"怎么排"去内部术语"母项目"、补"院线电影"注脚，符合决策 9）。
- **A1 调整**：开发压缩版删掉了"跨宇宙角色"——该词是补课链核心主题之一（跨宇宙角色入局），概述删除属信息损失。**改为以下版本落地**（可见宽 ≤54）：

  > **8 部精简补课路线。终局之后时间前跳、多元宇宙开启、跨宇宙角色与新英雄入局——补完接上《复联5：毁灭之日》。**

  压缩要点：删"之战"（终局之战后→终局之后）、删"接连"（接连入局→入局）、删"即可"（补完即可接上→补完接上）；**保留"跨宇宙角色"**。开发按其可见宽口径再核一遍 ≤54。
- 规格同步：设计稿 §10.1（复联5补课"为什么/怎么排"、主线精选"怎么排"）与 §10.2（黑豹/奇异2/洛基S1）及对应 mock 已更新为追认/调整后文案，**开发以 V2.0-R4 设计稿为准**，如仍有 >预算则回挂待裁定，不得自行再压缩。

### 4. 行高口径（L3）→ **以像素值 12px/16px 为准**

- §6"行高 ≥1.4"与 12px/16px（1.33）矛盾，裁定：**行高 16px（行高比 1.33）为硬口径**，表述已改为「正文 ≥12px、行高 16px（行高比 1.33）」。开发按 12px/16px 像素值实施（现状即如此，无需改代码），仅规格表述修正。

### 5. 缺陷修复（轨道 overflow:hidden 裁页）→ **确认，无规格违反**

- 开发自测修复方向（裁剪交给画布根容器 `.mcu-route-canvas` overflow:hidden、轨道不设 overflow）与规格 §9 一致，确认有效，无需回退；已记入实施报告遗留处理。
