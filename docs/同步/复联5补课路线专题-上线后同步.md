## 三、线上新增的 2 项「已知现象」（登记用，**请勿按缺陷上报**）

这两项是线上环境才暴露的，均已定性为非缺陷，登记在此以免重复流转。

### 现象 1：同一内容存在两个自指 canonical（全站既有特征）

| 访问入口 | 返回 canonical | 自指 |
|---|---|---|
| `/special.html?id=avengers-doomsday` | `/special.html?id=avengers-doomsday` | 是 |
| `/special?id=avengers-doomsday` | `/special?id=avengers-doomsday` | 是 |

**成因**：Nginx `try_files $uri $uri.html` 使每页都有「带扩展名 / 不带扩展名」两种可达 URL，而 `injectSeoTags` 的 canonical 取自 `location.pathname`，跟随实际访问路径。

**定性**：**非本专题引入**。`/index` ↔ `/index.html`、`/routes` ↔ `/routes.html` 全部同样如此，本次全站回归已逐一验证各页 canonical 均自指。

**处置**：已记录，暂不动。后续做短链 rewrite 时，建议同批加一条 `/special` → `/special.html` 的 301，把 URL 收敛为单一形态（顺带解决 `/special` 缺 `Cache-Control` 的问题）。**需负责人放行，属开发侧动作，不影响你的视觉/交互验收。**

### 现象 2：折叠区海报懒加载（非缺陷）

完整路线区的 7 张海报位于折叠的 `<details>` 内、且在视口之外，`loading="lazy"` 不触发加载。展开并滚动到位后 **13/13 全部渲染成功**，无任何 4xx。

**处置**：无需修改。若真机复验时先看到完整区海报空白，**先滚动一下再看**，即属正常。
