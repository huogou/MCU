# 开发授权单（MCU 观影助手 GenUI V2.0 · 信息架构重设计）

> 发放方：设计 AI（规格 V2.0-R3 已冻结）｜接收方：CodeBuddy（开发 AI）｜转交人：策划（用户）
> 设计规格以 V2.0-R3 修订稿为准；本单六部分齐全（授权范围/必读文件/红线/首日必做/停止条件/过程要求）。

## §一 授权范围

### 本次要做（编号逐条）

1. **重写画布渲染**（`版本迭代/GenUI小工具/genui-app/index.html`）：将 V1.0 顺序列表（可上下滚动）整体重写为 V2.0 分页结构——每条路线 = 1 页路线介绍（适合谁/为什么/怎么排/看完获得 4 块）+ N 页作品（每页 1 部，kicker 序号/总数 + 推荐级别徽章 + 4 文字字段 + 页码条 + 2px 金色作品进度条）。滑动/◀▶ 翻页、页码/总页数、首末页禁用态、切路线重置第 1 页、重置回新手入门 1/13，全部按设计稿 §8 执行。
2. **扩展数据构建**（`genui-app-tools/build-data.cjs`）：从母项目 `h5/data/{routes,special-routes,movies,series,relations,upcoming}.js`（只读）抽取并生成 V2.0 数据，重新产出 `genui-app/static/data.js`——含每条路线 `intro{forWho,why,order,outcome}` + 每条目 `badge/reason/role/gains/next`（字段来源与派生规则见设计稿 §11.1/§11.2）；**新增长度断言**（字段超预算即构建报错退出，根除文字截断）。
3. **更新 E2E**（`genui-app-tools/e2e-visual.cjs`）：删除/改写 3 项旧断言（"列表可上下滑动/主线精选可滚动/切换后列表位置重置"）；新增断言：无垂直滚动、页码精确、翻页正确、滑动不切路线、字段行数 ≤ 预算、徽章三态、进度条宽度 (k−1)/N、kicker 序号正确、首末页按钮禁用 no-op、切路线页码重置、重置回默认、console 零错误。
4. **本地完整自测**：build-data 构建成功 + 长度断言全过 + guard-frozen.cjs 全绿（预计零改动）+ e2e 双视口（360/414）全绿 + 控制台零错 + 画布零横向溢出/零截断。
5. **产出实施报告与独立构建**：按 7 项模板报告（含实际路径/初始化与台账同步结果等）；构建产物与提审包候选归档，记录 SHA-256。

### 明确不做（防跑偏，逐类列出）

- **不改母项目 `h5/` 任何文件**（只读引用；数据字段缺失或超预算时→回设计侧挂"待裁定"，不得自行补数据或编造）。
- **不改冻结外壳** `.vc-*` / `.cos-*` 结构与官方 Tabs（含操作区布局）；违反 = guard-frozen 失败 = 交付不通过。
- **不 git 提交**（设计侧独立复核通过前）；改动仅限 `版本迭代/GenUI小工具/` 目录内。
- **不提审、不部署、不替换正式发布物**（genui-app.zip 等历史备份不得触碰；提审由策划/用户执行并记录 SHA-256，防 V1.0 旧包错位重演）。
- **不新增外部资源**：无图片素材、无外链、无第三方依赖（平台合规红线）。
- **不启用跳转浮层**（编号网格为条件功能，平台容器浮层能力未验证前默认不启用，保持纯进度展示）。
- **不自行修改设计规格**：与设计文档冲突处停止并挂"待裁定"。

## §三 红线重点（最易踩的置顶）

1. **冻结件零改动**：`.vc-*` / `.cos-*` 结构与官方 Tabs 一个字节都不动；guard-frozen.cjs 必须全绿（违反 = 交付不通过）。
2. **保留函数名**：`onTabChange / resetDemo / sendLog / showTipsTooltip / adjustTipsTooltipPosition`（guard 断言依赖，改名 = 失败）。
3. **母项目 h5/ 只读**：禁止新增第二套数据源；洛基 S2 年份 2023 沿用 V1.0 已验收口径（build-data 覆盖表，注释来源）。
4. **复联5 表述边界**：仅允许母项目已验证层面（多宇宙汇合关键一方 / 做汇流准备 / 做人员储备 / 三条线汇合到毁灭博士 / 毁灭博士登场）；**禁止写入任何未经官方确认的未上映剧情**；字段超字数预算一律由长度断言拦截（不得用省略号截断）。
5. **不 git 提交 / 不提审 / 不部署**：仅限 genui-app 与工具链目录改动，等待设计侧独立复核。

## §四 首日必做（按序执行，全部通过才继续开发）

1. **读授权单与必读文件**：先完整阅读本单 + 设计稿 §5–§9/§11（CodeBuddy 自行读取设计包原文，策划不做转述）。
2. **基线核对**：确认 `genui-app/index.html`、`static/data.js` 与 git HEAD `519a820` 一致（工作区零差异）；记录关键文件 SHA-256 到实施日志。
3. **工具链现状验证**：先按原样跑一次 `build-data.cjs` + `guard-frozen.cjs` + `e2e-visual.cjs`，确认 V1.0 基线全绿后再动手改造（环境/Node 依赖确认）。
4. **扩展 build-data.cjs**：生成 V2.0 `static/data.js`，验证：25 个渲染条目（去重 24 id）全部覆盖 role/sf/badge 源/next 或 kw；长度断言全过；体积估算 23–28KB 可接受。
5. **重写 index.html 画布** → 本地 e2e 双视口全绿 + 控制台零错 → 进入自测收口。
（本任务无外部样本依赖，无"样本未到位"项。）

## §五 停止条件

- 完成上述自测（build-data 断言全过 + guard 全绿 + e2e 双视口全绿 + 控制台零错 + 零溢出/零截断）后**停止**，不得扩大范围。
- 产出独立构建与提审包候选到 `版本迭代/GenUI小工具/` 指定位置（记录 SHA-256），**不触碰** genui-app.zip 正式备份、历史版本目录与 git。
- 交付 7 项实施报告后等待**设计侧独立复核**（对照设计稿 §14 十五项账单 + §16 平台级测试：genui preview / genui check / 真机）；复核通过并获明确授权后才允许打包提审。

## §六 过程要求

- 每轮按固定 7 项模板汇报：交付物与实际路径 / 核心结论 / 文档同步 / 遗留问题 / 下一步 / 需要决策项 / 风险。
- 过程实时留档到 `版本迭代/GenUI小工具/` 下实施日志（如 `V2.0实施日志.md`），不留档视为未完成。
- 遇设计歧义、数据缺失、断言失败与设计文档冲突时，**停止实施**并在报告中挂"待裁定"，不得自行修改设计或编造数据。
