## 二、设计规范（浓缩版）

**定位**：科技资料库 × 电影档案。禁止：漫威红黑、海报墙、粒子特效、游戏 UI、宣传海报风。用户 3 秒理解"这是规划漫威观看顺序的工具"。

**色彩**（画布内，浅色 COSUI 外壳上）：
- 底 `#f7f5f0` 米白 ｜ 纸 `#ffffff` ｜ 深墨 `#1a1d23` ｜ 次级 `#4a4f58` ｜ slim `#8a8f99` ｜ 线 `#e8e5de`
- **档案金 `#b8860b`**（⚠️ 不是母项目的 `#F2B233`——白底上对比不足，已降饱和，勿回退）
- 阶段六色：P1 `#3a5ba0` / P2 `#a03a3a` / P3 `#b8860b` / P4 `#6b4fa0` / P5 `#2a7a5a` / P6 `#a04a2a`（程序化卡 hero 渐变按阶段取色）
- 金底 `#fdf6e8` / 金线 `#e8d5a8`（标签/胶囊用）

**字体**：正文系统栈（-apple-system/PingFang SC）；**编号/年份一律等宽栈** `SF Mono, Menlo, Consolas`（数据库感的核心来源，勿丢）。

**画布**：1:1 卡片，360 视口 = 326×326px。F1 视图有冻结件 chips 占 30px → 内容区仅 **193px**；F3/B 为 **227px**。414 视口 380×380。8px 间距网格。

**图片策略**：C 混合方案——核心作品真实海报，其余程序化 CSS 卡（阶段色渐变+胶片孔底纹+罗马数字+「MCU 档案」角标）。零外部资源、零大图依赖。

## 三、接手注意事项（血泪坑，按杀伤力排序）

1. **平台硬规范 > 设计建议**。360px 是最坏情况预算基准，**每加一个元素先算总高**——V1.2 就是加了内容没做预算，导致按钮/理由被滚出可视区。
2. **容器内滚动裁切 e2e 检测不到**：`boxOverflow:false` 不代表没裁切，必须看 `bodyScrollH ≤ bodyClientH`（现已 12 条断言，新增断言见指令第五节）。
3. **冻结件不可动**：GenUI Header、COSUI 组件、官方按钮、官方 token、`:root`、F1 顶部 chips 行。只有 **`.mcu-*` 作用域**是设计可改区。每轮回执必写"铁律三项"（影响端/红线/Token）。
4. **渐隐 mask 会吞内容**：引导文案、当前项理由绝不能放进滚动渐隐区（V1.2 实锤翻车点）。
5. **隐形元素吃预算**：B 卡曾有被 flex 压成 0 高的重复片名——截图看不见但占高度，审查 DOM 不要只看截图。
6. **装饰元素必须承载信息**：FILM ARCHIVE 条、独立进度行这类纯装饰已被逐轮清掉，别再加回来；审核对"占位不传递信息"零容忍。
7. **基线冲突已裁定**：V1.1 基线第 5 条（换一部权重≤Tab）**已作废**，现行标准是金色胶囊（灰度测试：换一部 = 画面第 2 明显可点元素）。
8. **审核标准会反转**：一轮嫌"空"，二轮嫌"挤"。平衡点 = 空白吸收机制（海报/hero 弹性生长为主、衔接条兜底），**任何视口内容区不留 >24px 连续空白**（将作为 e2e 断言）。
9. **流程纪律**：开发落地 → 跑 `genui-app-tools/e2e-visual.cjs`（360/414×F1/F3/B 六图+程序化卡专项图+`e2e-visual-result.json`）→ 设计**逐帧**复核截图（不能只看数据全绿）→ 回执放行/驳回。工具链 `extract→apply` 已同步 live 且幂等（SHA256 验证），走查顺序见回执第七节。
10. **提审物料已就绪**：Logo `genui-app-tools/mcu-logo-marvel-256.png`（256×256 PNG 82KB，含六色无限宝石+M 的漫威元素版）；上传包重打包须含 live 产物。
