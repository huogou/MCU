## 五、设计资产存放原则

1. **视觉设计稿（GenUI html 等）**：当前在 `docs/产品/`（被 `docs/同步/*.md` 引用）。如需集中到仓库根 `design/`，须负责人授权并同步更新引用——**本轮未移动**。
2. **外宣图片（png/jpg）**：在 `docs/外宣物料/`，属素材库，不强制移 `design/`。
3. **仓库根 `design/`**：存放微信 V1.2 视觉预览等，与 docs 内资产**无重复副本**（已核验）。
4. **铁律**：设计资产不得删除；移动须授权并校验引用；疑似重复文件须确认后再处理，不得自动删除。

## 七、新文件应该放在哪里的判断规则

1. 产品方案 / 功能设计 / 视觉稿 / 资讯 → **产品**
2. 版本记录 / 各端版本 / CHANGELOG / 升级盘点 → **版本**

4. AI 间同步 / 授权 / 验收 / 裁定（GenUI 轻量）→ **docs/同步**；正式角色分桶协作 → 根 **同步/**

6. 论坛后端 API 设计 / 测试 / 审计 → **论坛API**
7. **不确定** → 暂放 **技术** 并登记待裁定，不擅自扩大移动范围。
