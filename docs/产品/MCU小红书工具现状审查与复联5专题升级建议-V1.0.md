## 5. 优化建议（现有版本）

- **保留**：F1 观影顺序（4 种排序生成器是核心差异化能力）、F2 节点探索（角色/作品关联含 `why`，是现成亮点）、F4 Canvas 卡片+端能力（H5 不具备的**唯一图片生成能力**，务必保留并强化）。
- **调整**：F4 卡片从"通用星系卡"改为"**观影进度卡 / 必看清单卡**"，更贴合小红书晒进度心智；把 XHS `data.js` 改为**从 H5 `h5/data/*` 自动生成**（参照 GenUI 的 `build-data.cjs` 思路），消除双份维护。
- **新增**：移植 H5 的 `MCU.progress`（已看/清单/里程碑，键 `mcu_nav_user_v1`）到 XHS，补齐 4.2 的能力缺口；补充剧集/短片数据口径。
- **删除/收敛**：当前无冗余功能；仅需收敛文档，使其与代码一致（见 §9 P0）。

## 6. 复联5专题（《复仇者联盟5：毁灭日》）可行性分析

### 6.1 是否建议增加：✅ 强烈建议

- **时机**：复联5 上映日 `2026-12-18`（`upcoming.js:45-55`，档期为官方确认）。上映前是补课流量高峰，现在（11 月）正是承接窗口。

- **XHS 缺复联5 入口是明显空白**（H5 已有，小红书工具没有），补全成本低、用户价值明显。

### 6.2 专题应定位为"上映前观影准备/补课"，**不得做复联5 本体内容**

> ⚠️ **剧情/角色事实边界（必须严格遵守）**

> - **禁止写成事实**：复联5 具体剧情、未官宣的角色与关联作品、票房/评价等。
> - 数据现状：`movies.js:38-46` 的 `doomsday` 仅 stub（英文片名+上映日+阶段+一句话 role/sf，`chars:[]`），**无剧情、无角色、无剧照**；`characters.js` 24 个角色中**无毁灭博士**，`relations.js` 无指向 `doomsday` 的边。

## 8. 小红书平台限制（以 Skill 基线文档为准）

| 约束 | 规则 | 对本案影响 |
|---|---|---|
| 离线运行 | 禁 `fetch/XHR`、禁外部资源，全部打包进 zip | XHS 已合规（外置脚本+内置数据） |
| 脚本 | 必须外置 `<script src>`、**经典脚本**（禁 `type=module`/import/export）、禁内联/`onclick`/`eval`/WASM/Worker/iframe | XHS 已合规 |
| **包体积** | 上传上限 **10 MiB**；建议 ≤2 MiB（历史文档 ❓ 已解） | XHS 现 44KB，即使补全剧集+海报也远小于上限 |
| 单文件/Base64 | 单文本 >2 MiB 提示、>5 MiB 文本合计提示；单条 Base64 解码 >1 MiB 必须改独立文件 | 数据走 `data.js`（90KB）无压力 |
| 存储 | `xhs.miniTool.setStorage`（客户端 9.46+，单 key ≤1MB、总 ≤10MB，JSON 字符串）+ localStorage 兜底；**不保证永久持久化** | 进度/清单用此；须容忍清理 |
| 分享/发布 | `postNote`：标题 ≤20 字、正文 ≤1000 字、图片 1–18 张、**媒体字段不接受 http(s)**（仅 data:/本地路径）；仅唤起发布页，不代表审核通过 | F4/复联5 分享卡走 `writeTempFile`→`saveImageToPhotosAlbum`/`postNote` |
| 图片保存 | `saveImageToPhotosAlbum` + `writeTempFile`（Canvas → 相册） | F4 已用，复用 |
| 评论 | `interactionOpenApi`（9.49+），用户手势触发 | 可选增强 |
| 剪贴板 | `navigator.clipboard` 禁用 → 引导长按/选中复制 | 分享文案用此 |
| 外链/多页 | 禁 `window.open`/`target=_blank`/站外跳转 → 单页内 JS 切视图 | XHS 已是单页 SPA，合规 |
| Canvas/WebGL | Canvas 2D 可用；WebGL 可用但受预算约束（DPR≤1.5、纹理≤2048、30FPS 目标） | 卡片用 Canvas 2D 即可，无需 WebGL |
| 审核/合规 | 容器 CSP 统一管控；脚本外置、无内联是硬门槛 | XHS 已满足 |

> 需**线上复核实项**（Skill 要求以 `miniapp-sandbox.xiaohongshu.com/minitool/doc` 当前文档为准）：Storage/FileSystem 的最低客户端版本与容量、`postNote` 最新字段、`interactionOpenApi` 适用范围。本报告以基线快照编写，线上若有更新须回填。

## 10. 推荐的最小可行升级版本（MVP）

**不做成大型产品**。在现有 `dist/` 基础上，只做 5 件事：

1. **对齐文档 + 回填包体积上限**（P0，纯文档，零代码风险）。
2. **接 H5 数据同步管线**，让 XHS `data.js` 自动从 `h5/data/*` 生成（P0，消除漂移，同时为复联5 路线自动获得）。
3. **移植 `MCU.progress`**（P1）：用户可标记已看、查看补课进度、里程碑——这是工具实用性的地基。
4. **新增复联5 专题视图**（P2）：双 CTA + 核心 8 部 + 完整 15 部 + 五段链（末环标注"推测"）+ 进度徽章，数据全部复用 `special-routes.js`。
5. **F4 卡片改造为"我的补课清单/进度卡"**（P1）：可一键存相册/发笔记，形成小红书传播钩子。

**明确不做（本期）**：复联5 角色关系/新角色资料、知识测试、人物探索大幅增强、复联5 本体剧情内容（禁止编造）。

预期收益：以**最低成本**补齐工具实用性（进度）、承接复联5 上映前补课流量、强化小红书可分享性，且不重复 H5 已有能力、不新建高风险推测数据。
