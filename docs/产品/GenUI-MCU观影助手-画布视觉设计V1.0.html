3核心设计元素说明
每个设计决策的理由与使用场景

时间轴线（F1 路线卡）

左侧 1px 细线贯穿列表，圆形节点承载序号。主线作品为深色实心节点，支线为浅色描边节点，当前推荐为金色高亮节点带光晕环。

作用：3 秒内传达「按顺序观看」的工具属性；视觉重量集中在左侧序号，符合从上到下的阅读流。

档案式编号系统

使用等宽字体（SF Mono / Menlo / Consolas）渲染编号、年份、阶段标签等数据类信息，强化「电影数据库」的工具感。

作用：与中文片名形成字体对比，信息分层更清晰；替代海报作为视觉锚点。

阶段色条与色点

F1 卡片顶部有六阶段渐变色条（呼应MCU六阶段结构），列表项用 6px 色点标识所属阶段。档案卡左侧用 4px 色条标识阶段。

作用：用最小面积传递阶段信息，不喧宾夺主，保持整体工具调性。

程序化视觉卡（无海报时）

几何化胶片图标 + 罗马数字阶段号 + 英文简称，背景为浅灰横格纸纹理（暗示档案本），两侧有胶片孔装饰。

作用：23 部无海报作品的兜底方案，保持视觉统一，不依赖外部图片资源。

  • --mcu-archive-gold-line — #e6d5a8

开发注意事项：
1. 所有新增颜色/字体 Token 均在 .mcu-* 作用域内声明，不污染全局。
2. 等宽字体优先使用系统等宽字体栈，不引入外部字体文件。
3. 程序化视觉卡全部使用 CSS 绘制（渐变 + 伪元素），零图片依赖。
4. 六阶段色值为浅色背景下调和版本，比母项目的深色模式阶段色饱和度低 15-20%。
5. 金色使用 --mcu-archive-gold: #b8860b，比母项目金色 #F2B233 暗，确保在白底上的对比度 ≥ 4.5:1（WCAG AA）。
5验收标准核对
对照任务书要求逐项确认
  • ✓
    适配 360px — 设计稿以 360px 宽度为基准，所有元素在该尺寸下完整显示无截断
  • ✓
    1:1 画布可阅读 — 画布区占比 ≥ 50%，信息密度适中，关键信息（片名/序号/年份）一屏可见
  • ✓
    不依赖外部资源 — 程序化视觉卡全部 CSS 绘制，等宽字体走系统字体栈，零外部请求
  • ✓
    符合百度搜索工具轻量化场景 — 无粒子特效、无游戏UI、无宣传海报感，工具属性明确
  • ✓
    与 COSUI 外壳协调 — 底色沿用 --cos-vcard-color-bg，不修改外壳 token，仅在 .mcu-* 内新增派生变量
  • ✓
    用户 3 秒理解用途 — 时间轴+编号+电影名的组合直观传达「观影顺序工具」属性
  • ✓
    开发可直接转换为 CSS — 所有设计元素均可用标准 CSS 实现，标注了完整的类名、Token、尺寸、颜色
