6.1 12px 可读性实测复核（V2.0-R1，依据 §16 测试边界）

  • 实测方法：本地 HTTP 服务 + Chromium，模拟手机视口（360×640 / 375×667 / 414×896）渲染本设计稿 mock；对 8 个 mock 画布逐字段测量计算样式（font-size / line-height）与文本实际行数。
  • 实测结果：正文 12px / 行高 16px 在全部 mock 中按预期渲染；360 口径下每行实测容纳 19 全角字（内容宽 238px ÷ 12px），字段行数全部 ≤ 预算（2/3/2/2）；360 内容区 227px 内骨架实测 225px（余 2px）；375/390/414 视口对应内容区 242/257/281px，逐级更宽裕。
  • 结论：12px 为当前布局约束（1 页 1 部 + 4 个文字字段 + 1 个推荐级别徽章 + 2–3 行 + 无滚动 + 不截断）下的合理下限——字段区预算 156px（实测 163px）由 12px/16px 行距决定；若升为 13px，行高需 18px、字段区 +12~14px，360 档必然溢出，需砍字段行数（信息增量/后续关联降为 1 行）——代价大于收益，故保留 12px。注意：此为设计 Mock 级实测结论，真机字体度量差异将在平台级复核验证（§16）。

八、交互规则（滑动 / 按钮 / 切换 / 重置 / 打点 / 无障碍）

8.1 左右滑动翻页（画布内，仅绑定 .mcu-page-track）

  • 事件：Pointer Events（pointerdown → setPointerCapture → pointermove 累计 → pointerup 判定）；降级 touchstart/touchmove/touchend。
  • touch-action:none 于轨道元素：从机制上禁用浏览器水平手势与纵向滚动（硬约束 1/9 双保险）。
  • 判定阈值：|Δx| ≥ 24px 且 |Δx| ≥ 1.5×|Δy|（方向锁定）；Δx<0 → 下一页，Δx>0 → 上一页。
  • 边界：首页右滑 / 末页左滑 → no-op（不翻页、不打点、无动画）。
  • 防抖：翻页后 300ms busy 锁，锁内忽略一切滑动与按钮触发；锁释放后反向滑动立即生效。

8.2 手势与路线切换隔离（硬约束 7）

  • 翻页监听只挂载画布轨道；操作区 Tabs 不绑定任何平移逻辑，只响应 tap/键盘。
  • 画布 touch-action:none 使横向手势无法冒泡/穿透到操作区——事件隔离 + 物理隔离双保险，滑动永远不会触发路线切换。

8.3 上一页/下一页按钮与进度条

  • 形态 [◀] [3/13] [▶] + 底部 2px 金色进度条；◀ ▶ 为 button 语义，aria-label="上一页/下一页"，键盘 Enter/Space 触发；点击与滑动共用 busy 锁。
  • 禁用态（首/末页）：opacity:.25 + aria-disabled="true" + 事件 guard 返回（不阻断 pointer-events，保证 aria 可读）。
  • 作品进度条：轨道 .mcu-pager-track（全宽 2px，#2A3447）+ 填充 .mcu-pager-progress（#F2B233，宽度 = 作品进度 (k−1)/N；介绍页 0%、末页 100%），transition: width .2s，内嵌于 26px 页码条、不额外占高。
  • 跳转入口（条件功能，默认不启用）：页码数字（如 3/13）设为可点击（button + aria-label"打开作品目录"），点击展开轻量浮层——作品编号网格（01…N 编号方块，单屏内不滚动、不触碰冻结外壳），点编号直达对应页。启用前置：需在实施阶段验证 GenUI 平台容器内浮层交互可用（真机 + genui preview）；若平台能力不允许或影响审核，保持纯进度展示即可，不阻塞 P0。

8.4 路线切换与重置

  • Tabs（官方 .vc-tabs-* 结构零改动）：点击 / Enter / Space → 渲染该路线第 1 页 + 页码重置 1/N；沿用 V1.0 键盘实现。
  • 重置（表头官方 refresh 钮）：回「新手入门」第 1 页 + Tabs 激活第 1 项 + 官方旋转动画（沿用 spinResetIcon）。
  • 打点：沿用 sendLog，覆盖路线切换 / 翻页 / 重置（area 建议 operation / page）。

8.5 无障碍

  • 轨道 role="region" + aria-label；页码容器 aria-live="polite"，翻页播报「第 3 页，共 13 页」；画布不抢占 Tab 焦点（轨道 tabindex="-1"）。
