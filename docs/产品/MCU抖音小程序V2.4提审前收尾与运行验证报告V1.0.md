### `wx:` 模板指令兼容性（重点风险，未通过验证）
- 全工程 `wx:` 指令 **61 处**（`wx:if` / `wx:for` / `wx:else` / `wx:key`），`tt:` 指令 **0 处**。

- 本项目是「重建」而非「搬家」，未做前缀转换。历史 V1.3.0 同类写法曾获内容类驳回（侧面说明页面可被看到），但按本轮要求**不得以历史记录判定通过**。
- 结论：`wx:` 是否能被 4.5.6 编译产物识别，**必须在 IDE 编译/真机确认**；若报渲染异常，需将 61 处机械替换为 `tt:`（本轮未做，属功能改动，超出本次授权范围）。
