§3 7 字段契约实现情况
----------------------------------------------------------------
封闭 7 字段集合（Object.freeze）：title / summary / category / related_movies / related_series /
related_characters / related_phases。
- 与 ai-normalizer(G5.5) AI_ALLOWED_FIELDS 一致（去掉 ai_model）；Provider 不得携带 ai_model 等额外字段。
- 字段集合封闭：校验器只认这 7 个 key，任何其他 key 一律越权。
- 类型契约（沿用 G5.5 既有）：title/summary/category = 非空字符串；related_* 四个 = array。
- category 6 值枚举、related_phases 整数 1–6：属 G5.5 下游规则，N1.1 不在本层重复（避免耦合/越界），报告 §14 标注为待决策。

----------------------------------------------------------------
§4 Validator 实现情况
----------------------------------------------------------------
`contract-validator.validate(result)`：
1) 非对象/数组 → RESULT_INVALID
2) 未知字段 → FORBIDDEN_FIELD（列出全部越权 key，不静默接受、不静默丢弃）
3) 缺失必填 → MISSING_FIELD（列出缺失 key）
4) 字符串字段非 string 或空串(trim 后) → TYPE_ERROR / MISSING_FIELD
5) 数组字段非 array → TYPE_ERROR
6) 通过 → 返回隔离副本（Object.assign({}, result)），绝不修改原始输入
校验失败不抛"成功"、不进持久化（由调用方负责拦截，adapter 直接向上抛）。
