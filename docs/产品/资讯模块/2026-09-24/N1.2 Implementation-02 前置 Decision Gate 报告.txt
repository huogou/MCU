五、S001 JSON / HTML 人工入口决策分析
----------------------------------------------------------------

本阶段不开发 HTML parser；以下仅分析。

方案 A：JSON-only（现状）

  · 技术成本：0（已实现并测试通过）。

  · 对真实 Live 帮助：中（S001 本身 manual-only，人工入口已匹配其定位）。
  · 是否值得现在做：已做，维持现状。

方案 B：HTML → raw capture（人工保存 HTML 再解析）
  · 使用场景：运营保存 marvel.com/news 列表页 HTML → 解析为原始条目。
  · 技术成本：高（须新写 html-parse：选择器/结构容错/反爬/结构变更维护）。
  · 对 G5.2 影响：须扩/改 parser（G5.2 属冻结件）→ 需先拍板解冻。
  · 审计/回放：原始 HTML 可留档，但解析规则需版本化管理。
  · 对真实 Live 帮助：高（S001 唯一出口本就是 HTML）。
  · 是否值得现在做：**不建议现在做**（成本高 + 触冻结件；现状 JSON 已满足人工录入）。

方案 C：JSON + HTML 双入口
  · 使用场景：兼顾结构化与原始 HTML 两种投递。
  · 技术成本：A + B。
  · 对 G5.2 影响：同 B。
  · 审计/回放：两入口并存，须统一 capture 口径与来源标识。
  · 对真实 Live 帮助：高。
  · 是否值得现在做：**不建议现在做**（先以 JSON 满足现状；HTML 待需要时单独评估）。

【结论】**需要产品拍板**。本阶段不修改当前 JSON 入口。

六、真实 Provider 安全边界检查
----------------------------------------------------------------
逐项核对「Provider → Adapter → Validator → Bridge → Normalizer」在接入真实 Provider 后是否仍成立：
  1) Provider 不能绕过 Adapter：✅ 架构上 runner 必经 runAdapter；但**非强制**——若调用方直接调 provider.provide 即绕过（当前无此调用路径，风险低）。建议真实 provider 仅经 runner 暴露。
  2) Provider 不能写入 ai_model：✅ contract-validator 为封闭 7 字段集，Provider 输出含 ai_model → FORBIDDEN_FIELD。
  3) Provider 不能增加未知字段：✅ 同上 FORBIDDEN_FIELD。
  4) Provider 失败不能进入正式数据：✅ runAdapter 抛 PROVIDER_ERROR；runner 不 catch。前提：调用方不 catch 吞掉（须约定）。
  5) Provider 调用不能自动触发 production：✅ orchestrator 未引用 ai-provider；无自动接线。
  6) Scheduler 默认仍关闭：✅ DEFAULT_DISABLED = true；run() 即便 enabled 也只到计划层，绝不执行 production。
  7) mock provider 仍保留：✅ 测试保留 mock；N1.1/N1.2 套件依赖。
  8) fixture 回归仍保留：✅ fixture 133 条 + 回归套件（N1.1 32 / D1/D2 42 / N1.2 53）。

【风险（只报告，不扩大修改）】
  ① 网络出口边界：http-transport.cjs 自述为「唯一允许联网模块」，但该限定在**采集层**。真实 AI Provider 联网将引入采集层**之外**的新出口 → 需明确：Provider 出口是否受同一 transport/UA/robots 体系约束，或另立 Provider 专用出口规范（含 UA 声明、超时、限流、审计）。
  ② 接线越权：ai-provider 目前未接入 orchestrator。接入时必须保证「必经 Adapter、不自动 production、不旁路 bridge」；否则 1)【不能绕过 Adapter】的"约定"会退化为"没有"。
  ③ 凭据/缓存外泄：D-P4/D-P5 引入的密钥与缓存，须确保不落入交付物/日志/news.js（与既有红线一致）。
  ④ runAdapter 将**整个 candidate** 传给 provider → 与 D-P7 出域范围直接相关（出域的不止 title，而是 35 字段 L1）。
