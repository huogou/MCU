■ 4.2 parser 的已知限制（如实记录）

  · **html-parse 明确出界**：S001（Marvel 官方）需要 HTML 列表页解析，
    按任务书 §5 明确排除。**本阶段无法采集任何来自 Marvel 官方的原始证据。**
  · **S003 ComicBook**：探活记录显示出口为 `/category/marvel/feed/`（RSS），
    但本次联网实测返回 403。可能原因：
      a) ComicBook 对非浏览器 UA 加了 Cloudflare / 反爬策略
      b) 探活时间（09-22）与本次（09-23）之间站点策略变更
    → 需要在下阶段尝试更换 UA 或使用 Cookie。

■ 4.3 **是否需要 HTML 专项**

  **是。** 理由：
  · S001（Marvel 官方）是 `html-parse` 类型，是 **官方确认证据的唯一自动来源**。
  · 没有它，`official_confirmed` 状态只能依赖人工提供 URL（R7.5），无法自动化。
  · 但建议在 G5 后续或 G6 之前做，不在本阶段内。

  ★ 建议的 HTML 专项范围：解析 marvel.com/news 列表页 HTML → 提取 /articles/ 链接
    → 逐条访问 JSON-LD → 过滤 comics/games → 产出 RawCapture。
    与 R6.2 中描述的实现路径一致。
