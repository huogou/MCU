1. 一、数据结构
============================================================

■ 1.1 载体与定位

  · 载体：`workspace\news\engine\registry\source-registry.json`（JSON）
  · 定位：**管道层数据文件**。不进 h5/data/；**任何字段都不得渲染进 H5**。
  · 性质：资讯来源的唯一登记表。owner_group 独立性、tier、抓取策略、健康状态
    一律以此表为准。
  · 单例加载：由 `news-registry.cjs` 在 require 时读入并建立索引，
    运行时只读、不写文件、不联网。

■ 1.2 文件结构（顶层）

  ```
  {
    registry_version : "V1.0"          // 登记表版本（与每条条目一致）
    built_at         : ISO8601          // 建立时间
    note             : string           // 使用纪律（不得渲染等）
    non_official_domains      : string[] // 附属黑名单（不登记为 official 的域名）
    non_official_domains_note : string   // 黑名单说明
    entries          : object[]          // 12 条来源，每条 20 字段
  }
  ```

■ 1.3 20 字段定义（冻结）

  ┌────┬──────────────────────┬──────────────┬────────┬────────────────────────────────────┐
  │ #  │ 字段                  │ 类型          │ 必填    │ 说明                                │

■ 1.4 枚举（冻结）

  tier              T1 官方 / T2 权威行业媒体 / T3 MCU 垂直媒体 / T4 社交·未具名爆料
  crawl_policy      auto_allowed / manual_only / ai_ban_named / ai_ban_notice / blocked
  health            ok / degraded / paused
  source_type       官方 / 权威媒体 / MCU垂直媒体 / 公告平台
  official_or_media official / media
  discovery_role    发现器 / 验证器 / 公告核实器 / 人工
  feed_type         rss / atom / html-parse / none
  non_official_domains（附属黑名单） disney.com / disneyplus.com（及各自 www 前缀）

  语义澄清（本次新增，用于消除歧义）：
    · **health 只描述「已启用来源的抓取健康度」**。未启用来源统一记 `ok`
      （表示未探测、无失败记录）。**不得使用 `—` / `n/a` 等枚举外取值。**
    · **crawl_policy 取值一律只写裸枚举值**，实测细节（HTTP 状态码等）写进 `note`。

4. 四、与 G1 判定器的连接方式
============================================================

■ 4.1 连接链路（单向依赖，无循环）

  ```
  news-judge.cjs            ← 判定逻辑（不含任何来源事实）
        │
        ▼
  news-judge-rules.cjs      ← 规则常量 + 转发登记表
        │  require('./news-registry.cjs')
        ▼
  news-registry.cjs         ← 加载器 + 校验器 + 索引
        │  fs.readFileSync（本地 JSON，零网络）
        ▼
  registry/source-registry.json   ← 来源事实的唯一权威源
  ```

  · G1 的判定逻辑（news-judge.cjs）**本次一行未改**。
  · 改的只有 rules 模块：原先内联的 `SOURCE_REGISTRY` / `OFFICIAL_SOURCES` /
    `NON_OFFICIAL_DOMAINS` 三个常量，改为从登记表加载。
  · 判定器对外 API 与输出契约**完全不变**（25/25 + 49/49 回归为证）。

■ 4.2 三处具体连接

  【连接 1】来源等级：`judge.tierOf(source_name)` → `registry.getTier()`
    · 已登记来源 → 返回登记表的 tier
    · **未登记来源 → 返回 T4**（判定器侧保守降级）
    · 注意设计：`registry.getTier()` 对未登记来源返回 **null**，
      而判定器返回 **T4**。二者刻意不同，以保持
      「未登记」与「登记为 T4」两种状态**可区分**。
    · 验证：12 条已登记来源的 tier 全部与登记表一致；未登记来源回落 T4 ✓

  【连接 2】官方来源登记：`R.OFFICIAL_SOURCES = registry.officialSources()`
    派生规则：`official_or_media === 'official'` **且** `allowed_domains` 非空
    · 派生结果：**S001 / S006 / S012** 三条
    · S010、S011 虽为 official，但域名未登记 → **不进入**官方来源登记
      → 天然满足「官方域名未登记则不得构成 official_confirmed」
    · 该派生规则取代了 G1 里手写的 OFFICIAL_SOURCES，从此**不会再出现
      「代码里的官方域名清单与登记表不一致」这类漂移**。

  【连接 3】不登记域名黑名单：`R.NON_OFFICIAL_DOMAINS = registry.NON_OFFICIAL_DOMAINS`
    · 4 项：disney.com / www.disney.com / disneyplus.com / www.disneyplus.com
    · 判定器在 R7.4 校验的首步即拦截这些 host

■ 4.3 tier 在判定链中的作用（未变，此处重申）

  · `reliable_group_count` 只统计 **tier ∈ {T1, T2, T3}** 的已确认 owner_group
    → 直接决定 Step 5（≥2 → multi_source_reported）与 Step 6（=1 → single_source）
  · **T4 来源不构成「可靠来源」**：B9 用例证明「独立组 1 但 tier=T4」不会误判为
    single_source；B10 证明「2 个独立组但均为 T4」不会误判为 multi_source_reported
  · owner_group 与 tier 共同决定结论：**owner_group 决定「算几个组」，tier 决定
    「这些组算不算可靠」**。二者都来自登记表，因此登记表是判定结论的事实基础。

■ 4.4 数据流（G2 后的完整形态）

  ```
  source-registry.json ──加载──▶ news-registry.cjs ──派生──▶ news-judge-rules.cjs
                                       │                            │
                                       │                            ▼
                                       │                     news-judge.cjs
                                       │                            │
   h5/data/news.js ──只读──────────────┴────────────────────▶  判定结果（8 态）
                                                                  │
                                                       （G6 闸门后才落库）
  ```

  · 登记表**只读**，判定器**不写回**登记表。
  · 判定器输出**不直接落库** —— 落库权在 G6 的人工审核闸门。
  · 登记表**不进入交付数据**，也**不进入任何页面**。
