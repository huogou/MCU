## 1. 根因回顾（已被审计证实，非推断）

`candidate-item.cjs` 的 `fromRawCapture`（L0→L1 候选构造）中：

- `reported_by`（约 L176-180）**始终**由 `capture.source_url` 构造：`source_url: capture.source_url`。即经 `raw-capture` 校验的可信采集 URL 永远在 `reported_by[0].source_url`。
- 但顶层 `original_source_url`（L220 原代码）仅由 AI 输出 `a.original_source_url` 决定；而 `news-analyzer.cjs` 的 7 字段契约（`SEVEN_FIELDS`）**不含** `original_source_url`，故 `a.original_source_url` 恒为 `undefined` → 顶层 `'')`。
- 结果：新生成候选的顶层 `original_source_url` 恒空，而真实 URL 只存在于 `reported_by[0].source_url`；经 `delivery-converter` 拷贝后，生产 news.js 的顶层 `original_source_url` 为空（实测 14/15 已发布条目即此现象）。
