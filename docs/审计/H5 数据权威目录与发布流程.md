# MCU Atlas H5 数据权威目录、适配方式与发布流程

> 本文件为第一轮基础修复新增的运维约定，用于解决「线上与本地数据漂移」。
> 本轮只做本地约定与工具，不改动任何服务器配置、不部署。

## 1. 权威目录

| 端 | 权威目录 | 数据格式 | 说明 |
|---|---|---|---|
| H5 | `h5/data/*.js` | `window.MCU_* = [...]` 全局变量 | **H5 端唯一权威源**。浏览器 `file://` 双击即可运行，不能用 `fetch()` 读本地 JSON |
| 微信 / 抖音小程序 | `shared/data/*.js` | `module.exports` | 由 `shared/sync_data.sh` 复制到 `wechat/data/`、`douyin/data/` |

**不强行合并三端数据结构**：`shared/sync_data.sh:7-8` 已明确写出 H5 为 `window.MCU_*` 格式、小程序为 `module.exports` 格式，「不在此脚本范围内，需另行机械适配（去 window 前缀），请勿直接复制」。本轮保持这个边界，只补上 H5 侧的检查工具。

## 2. 数据漂移的根因

`sync_data.sh` 只同步 `shared → wechat/douyin`，H5 数据靠人工适配；线上又由生产流水线追加资讯与作品，导致线上长期领先本地。第一轮修复前实测：线上 62 部内容 / 56 处资讯 id 字面量，本地 59 部 / 49 条资讯。

因此约定：**H5 数据的发布与回同步必须走同一个检查入口**，禁止直接手工改服务器上的文件后不回写本地。

## 3. 发布流程（本地阶段，部署需另行人工确认）

1. **先查漂移**
   ```
   node h5/tools/check-live-local-diff.cjs
   ```
   比较线上与本地各数据集合的 id（不是全文 hash，避免新增字段被误判）。
   - `PASS`：集合一致，可继续。
   - 出现「线上独有」：先按线上回同步到本地（只读下载 `https://www.mcuatlas.xyz/data/<file>.js` 覆盖对应本地文件），再继续。
   - 出现「本地独有」：确认是本次有意新增，还是漏部署；不得直接覆盖线上。
   - `--full` 可额外列出页面/配置文件的全文差异，作为「本次将部署哪些文件」的清单。
2. **本地改动**：只改 `h5/data/*.js` 与必要的 `h5/` 页面，不改其他端的数据副本。
3. **本地回归**
   ```
   node h5/tools/regression-basic.cjs
   ```
4. **重新生成并校验 sitemap**（作品/路线/专题增删后必做）
   ```
   node h5/tools/generate-sitemap.cjs
   node h5/tools/generate-sitemap.cjs --check
   ```
5. **部署前人工确认**：部署清单、Nginx 301 规则（见第一节修复报告的部署建议）、回归结果、以及待核实内容标记。本轮不部署。

## 4. 数据纪律

- **发布状态**：新增未上映作品必须写 `releaseStatus: 'upcoming'`；`h5/data/content.js` 会把它保留在 `MCU_CONTENT_ALL`（供详情/关系/未来计划引用），但排除出 `MCU_CONTENT`（资料库、路线、下一部推荐、进度、统计、地图、sitemap）。缺省条目自动注入 `releaseStatus: 'released'`。
- **不删 ID**：未上映作品保留原 id，历史 `localStorage['mcu_nav_user_v1']` 中的记录不会被清理或改名。
- **正式中文片名唯一**：以 `movies.js` / `series.js` 的 `cn` 为准；`upcoming.js` 的 `title` 必须与之相同。未来计划条目通过 `contentId` 关联作品详情，`next.html` 据此去重。
- **待核实标记**：无法确认的官方档期、剧情关联、集数等，写 `pendingReview: true` 并在注释说明；`components.js` 会把这类未来作品显示为「档期待核实」而非「已定档」。资讯正文为历史报道文本，不因片名统一而改写。
- **规范 URL**：首页 `/`、专题 `/special.html?id=<id>`；`/index.html` 与 `/special` 为重复入口，不进 sitemap，服务器 301 需部署阶段人工确认。

## 5. 工具清单

| 工具 | 作用 | 是否写文件 |
|---|---|---|
| `h5/tools/check-live-local-diff.cjs` | 发布前线上/本地数据集合差异检查 | 否（只读） |
| `h5/tools/regression-basic.cjs` | 本地数据 + SEO 基础设施回归断言 | 否 |
| `h5/tools/generate-sitemap.cjs` | 按本地数据生成 sitemap | 默认写 `h5/sitemap.xml`；`--check` 只读 |
