## ⚠️ 六条最容易踩的坑

1. **测试报告 / 验收报告 / 提审报告 ≠ 设计资产。** `design/` 只放「长得好看的」，报告类一律进 `docs/版本/`。
   *（真实教训：曾有 44 个报告文件混进 `design/小程序/`，2026-10-15 已清理归位）*
2. **PM 进度文档 ≠ 脚本。** `workspace/` 只放代码与探针产物，「XX升级进度盘点」要进 `docs/版本/`。
3. **同步件三要素**：`.md` 扩展名 · 每次**新建**文件（禁改禁覆盖） · 多任务建任务子目录。
4. **设计稿与设计规格要同处**：`design/` 里的 md 规格若指向原型 html，原型也应在 `design/` 同名子目录。
5. **不确定归属时**：放进 `workspace/_待归位/` 并登记（路径 + 原因 + 建议归属 + 是否需确认），**不要**丢根目录，**不要**自行移动已有文件。
6. **发现别人放错了**：先登记 + 给归位建议，**不自行扩大移动范围**。
