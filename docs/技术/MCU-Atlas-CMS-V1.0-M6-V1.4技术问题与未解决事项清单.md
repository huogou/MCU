## 停止条件

1. **I-03 失败**：G3 必须改冻结代码才能拦截 → 停止，等待 Owner 决定解冻。

4. **网络隔离无法提供固定 IP 证据** → 停止并销毁 VM。
5. **指标无法按 V1.4 口径计算** → 停止，先修定义。
