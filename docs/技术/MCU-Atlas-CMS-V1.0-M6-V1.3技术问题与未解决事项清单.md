## 停止条件（对应任务五）

1. **I-02 失败**：G3 必须改 M1–M5 冻结代码才能拦截 → 停止，提交证据，等待 Owner 决定是否解冻；不得自行修改。
2. **I-04 失败**：helper 无法在空 capability 下完成白名单操作 → 停止，评估 0644/能力/helper 设计；不得直接放宽到宽权限。
3. **systemd 239 无法实现必要隔离** → 停止，记录不支持的参数，重新设计 unit；不得用更宽权限绕过。
4. **网络隔离无法提供可靠证据**（固定 IP 仍可连、抓包有流量）→ 停止并销毁 VM。
5. **指标无法按 V1.2/V1.3 口径计算** → 停止，先修指标定义，不得用估算替代。
