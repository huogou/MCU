# MCU 观影助手 · 画布视觉优化指令 V1.1

> **出具方**：设计 AI ｜ **日期**：2026-10-13 ｜ **对象**：开发 AI（CodeBuddy）
> **触发原因**：百度 GenUI 预览实测截图反馈，画布区视觉紧凑感失衡
> **作用范围**：仅 `.mcu-*` 画布内容区样式；**不触碰** GenUI 外壳、COSUI 组件、官方 Token
> **优先级**：P0 必改 / P1 建议改 / P2 可选优化
> **依据**：用户上传的 F3 随机探索视图截图 + V1.0 设计稿（`docs/产品/GenUI-MCU观影助手-画布视觉设计V1.0.html`）

---

## 0. 一句话定位

> **当前问题**：信息层"该松的地方紧，该紧的地方松"——核心视觉资产（海报）被多层叠加信息侵蚀，底部操作区主次不分。
>
> **优化目标**：3 秒内让用户看到「海报 + 片名 + 一句推荐理由」，其余信息按需展开。

---

## 1. 问题清单（基于截图实测）

### 1.1 F3 随机探索卡 · 卡片信息层堆叠（P0 · 严重）

**截图证据**：海报上同时叠加 4 层信息：

| 层 | 内容 | 位置 |
|---|---|---|
| ① 右上角角标 | "第三阶段" 深色半透明标签 | 海报右上 |
| ② 渐变层顶部 | 黄色圆点 + "第三阶段 2019 主线必看" | 海报下沿叠加 |
| ③ 推荐理由入口 | 黄色警告图标 + "为什么要看..." | 渐变层下 |
| ④ 剧情简介 | 截断的 "是...的终章..." | 渐变层最下 |

**核心问题**：
- "第三阶段" 在同一卡片内出现 **2 次**（角标 + 渐变层）
- 4 层信息零间距叠加在海报上，海报被"围攻"
- 渐变层文字行距约 1.2 倍，远低于 WCAG 建议的 1.5 倍

### 1.2 顶部信息冗余（P0 · 严重）

| 层级 | 现状 | 问题 |
|---|---|---|
| 大标题 | "MCU观影助手" | OK |
| 副标题 | "漫威电影宇宙观看顺序生成工具，帮助用户快速规划观影路线，查看作品时间线与关键节点。" | 40+ 字长句，无信息分层 |
| 面包屑 | "小工具 · MCU观影助手" | 与大标题完全重复 |

### 1.3 底部操作出口过多（P1 · 中等）

| 出口 | 现状 | 权重 |
|---|---|---|
| 「观影路线」Tab | 浅色背景 | 中（与"随机探索"同权重） |
| 「随机探索」Tab | 白色背景+阴影 | 中（当前选中态） |
| 「换一部」文字链 | 蓝色高饱和 | 高（颜色权重远超 Tab） |

→ 3 个出口挤在一屏底部，且"换一部"用蓝色文字压过 Tab 选中态，**视觉主次倒置**。

### 1.4 间距系统缺失（P1 · 中等）

| 区域 | 现状 | 建议 | 偏差 |
|---|---|---|---|
| 副标题→面包屑 | ~16px | 20-24px | 略紧 |
| 海报→信息层 | 0px（叠加） | 0px 但需精简叠加内容 | 核心问题 |
| 信息层文字行距 | ~1.2 倍 | 1.5-1.6 倍 | 过紧 |
| 卡片→按钮区 | ~20px | 24-32px | 略紧 |
| 双按钮之间 | ~12px | ≥16px | 触控安全区不足 |
| 按钮→「换一部」 | ~8px | 16px | 层级黏连 |

## 2. 优化指令（逐项落地）

### 指令 2.1｜F3 卡片信息层做减法（P0）

**目标**：海报上仅保留 1 层信息（阶段角标），其余信息移至卡片下方独立信息区。

#### 2.1.1 移除冗余角标

**文件**：`genui-app/index.html`
**位置**：`renderRandom()` 函数中生成 `mcu-discover-phase-tag` 的代码块

**修改前**（V1.0 现状，参考设计稿）：
```html
<span class="mcu-discover-phase-tag">第三阶段</span>
```

**修改后**：保留此角标，**移除**渐变层中重复的 "第三阶段" 文字。

#### 2.1.2 渐变层信息精简

**修改前**（截图实测的渐变层结构）：
```html
<div class="mcu-discover-hero-overlay">
  <div class="mcu-discover-meta">  <!-- 黄点+第三阶段+2019+主线必看 -->
    <span>第三阶段 2019 主线必看</span>
  </div>
  <div class="mcu-discover-reason-label">为什么要看</div>
  <div class="mcu-discover-reason-text">是...的终章...</div>
</div>
```

**修改后**（仅保留片名在海报上）：
```html
<div class="mcu-discover-hero-overlay"></div>  <!-- 仅做渐变，不放文字 -->
<div class="mcu-discover-hero-title">复仇者联盟4：终局之战</div>
```

**新增 CSS**：
```css
.mcu-discover-hero-title {
  position: absolute;
  bottom: 12px;
  left: 14px;
  right: 14px;
  z-index: 2;
  color: #fff;
  font-size: 16px;
  font-weight: 600;
  line-height: 22px;
  text-shadow: 0 1px 4px rgba(0,0,0,0.5);
  overflow: hidden;
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
}
```

#### 2.1.3 卡片下方独立信息区重构

**目标结构**（替换原 `mcu-discover-body`）：

```
┌─────────────────────────┐
│ [海报 + 阶段角标 + 片名]  │  ← 视觉焦点（仅 3 个元素）
├─────────────────────────┤
│ 2019 · 第三阶段 · 主线必看 │  ← 元信息行（单行 chip）
├─────────────────────────┤
│ ★ 为什么看这部            │  ← 推荐理由标签
│ 漫威宇宙的终章之作...      │  ← 推荐理由正文（3 行截断）
├─────────────────────────┤
│ 🔄 换一部继续探索  MCU#07 │  ← 底部提示条（含换一部入口）
└─────────────────────────┘
```

**CSS 关键调整**：
```css
.mcu-discover-body {
  padding: 12px 14px 10px;  /* 原 12px 14px 14px，底部减 4px */
  gap: 10px;                /* 原 8px，增至 10px */
}

.mcu-discover-reason-text {
  font-size: 13px;
  line-height: 19px;        /* 原 18px → 19px，行高 1.46 */
  -webkit-line-clamp: 3;
}

.mcu-discover-foot {
  padding-top: 10px;        /* 原 8px，增至 10px */
  border-top: 1px dashed var(--mcu-line);
}
```

### 指令 2.2｜副标题精简（P0）

**文件**：`genui-app/index.html` 的 `<style>` 段
**目标类**：`.vc-component-tips-tooltip`（提示气泡文案）

**修改前**（截图实测文案）：
> "漫威电影宇宙观看顺序生成工具，帮助用户快速规划观影路线，查看作品时间线与关键节点。"

**修改后**：
> "选一条观影路线按顺序看，或切到随机探索让 AI 推荐一部。"

**理由**：
- 字数从 40+ 缩至 24 字
- 动词前置（"选"/"切到"），用户 1 秒抓到操作动作
- 移除"生成工具""帮助用户"等填充词

**同步修改位置**：`renderRoute()` 函数内的 `mcu-route-tagline` 若同样冗长，参照此原则精简。

### 指令 2.3｜底部操作区层级梳理（P1）

**当前问题**：
- 「观影路线」「随机探索」Tab 同权重
- 下方蓝色「换一部」文字链压过 Tab 选中态

**优化方案 A｜弱化「换一部」（推荐）**

将「换一部」从底部操作区移至 F3 卡片底部提示条内（见 2.1.3 结构图），改为图标+文字组合，颜色降为次级文字色 `var(--cos-color-text-slim)`。

**修改前**：
```html
<div class="mcu-operate-row" id="mcu-random-actions">
  <button class="vc-button vc-button-plain" id="mcu-shuffle">换一部</button>
</div>
```

**修改后**：
```html
<!-- 底部操作区仅保留 Tabs，不再单独放"换一部"按钮 -->
<!-- F3 视图的"换一部"入口移至卡片底部提示条 -->
```

**F3 卡片底部提示条改造**：
```html
<div class="mcu-discover-foot" id="mcu-discover-foot" role="button" tabindex="0">
  <div class="mcu-discover-foot-left">
    <span class="mcu-discover-foot-icon">🔄</span>
    <span class="mcu-discover-foot-text">换一部继续探索</span>
  </div>
  <span class="mcu-discover-foot-right">MCU#07</span>
</div>
```

**新增 JS 事件绑定**：
```js
var discoverFoot = document.getElementById('mcu-discover-foot');
if (discoverFoot) {
  discoverFoot.addEventListener('click', shuffle);
  discoverFoot.addEventListener('keydown', function(evt) {
    if (evt.key === 'Enter' || evt.key === ' ') {
      evt.preventDefault();
      shuffle();
    }
  });
}
```

**CSS 调整**：
```css
.mcu-discover-foot {
  cursor: pointer;
  -webkit-tap-highlight-color: transparent;
  transition: background 0.15s ease;
}
.mcu-discover-foot:active {
  background: var(--cos-color-fill-quaternary);
}
```

**优化方案 B｜保留底部按钮但弱化视觉权重**

若不愿改动 JS 事件绑定结构，仅做视觉弱化：
```css
.mcu-operate-row .vc-button {
  height: 32px;                    /* 原 34px → 32px，更紧凑 */
  font-size: 12px;                  /* 原 13px → 12px */
  color: var(--cos-color-text-minor); /* 不用 primary 色 */
  background: transparent;          /* 透明背景，不用 plain */
  border: 1px solid var(--cos-color-border-minor);
}
```

> **推荐方案 A**：操作入口收敛到卡片内，底部操作区只留 Tab 切换，信息架构更清晰。

### 指令 2.4｜间距网格标准化（P1）

**目标**：建立 8px 基数间距系统，覆盖画布区所有垂直间距。

| 区域 | 现状 | 调整为 | 涉及类 |
|---|---|---|---|
| 路线头部内边距 | 14px 15px 10px | 14px 16px 12px | `.mcu-route-head` |
| 时间轴列表项垂直间距 | 7px | 10px | `.mcu-tl-item` padding |
| F3 卡片内边距 | 14px | 14px 16px | `.mcu-discover-canvas` |
| F3 卡片信息区间距 | 8px | 10px | `.mcu-discover-body` gap |
| F3 推荐理由区上间距 | 4px | 8px | `.mcu-discover-reason` padding-top |
| F3 底部提示条上间距 | 8px | 10px | `.mcu-discover-foot` padding-top |
| 操作区与画布区间距 | 10px（gap） | 12px | `.vc-component-card-wrapper` gap |

**全局间距变量建议**（新增到 `.mcu-canvas` 作用域）：
```css
.mcu-canvas {
  --mcu-space-xs: 4px;
  --mcu-space-sm: 8px;
  --mcu-space-md: 12px;
  --mcu-space-lg: 16px;
  --mcu-space-xl: 24px;
}
```

## 3. 验收基线

完成上述修改后，开发 AI 需自测以下指标：

| # | 指标 | 要求 | 自测方法 |
|---|---|---|---|
| 1 | 海报叠加信息层数 | ≤ 2 层（角标 + 片名） | 截图检查 |
| 2 | "第三阶段"在同一卡片内出现次数 | ≤ 1 次 | DOM 搜索 |
| 3 | 副标题字数 | ≤ 30 字 | 文本统计 |
| 4 | 底部操作区出口数 | ≤ 2 个（Tab + 卡片内入口） | DOM 检查 |
| 5 | 「换一部」视觉权重 | ≤ Tab 选中态权重 | 截图对比 |
| 6 | F3 卡片信息层文字行距 | ≥ 1.4 倍 | DevTools 检查 |
| 7 | 360px 画布区占比 | ≥ 50% | `genui preview` 实测 |
| 8 | 1:1 卡片无溢出 | 无滚动条 | `genui check` |
| 9 | 触控安全区 | 相邻可点元素间距 ≥ 16px | DevTools 测量 |

## 6. 风险提示

| # | 风险 | 等级 | 应对 |
|---|---|---|---|
| 1 | 「换一部」移入卡片后，用户可能找不到 | 中 | 卡片底部提示条做整行可点 + 视觉 hover/active 反馈 |
