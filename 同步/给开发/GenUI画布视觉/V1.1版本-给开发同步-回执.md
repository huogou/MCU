## 1. 逐项复核结论

### 偏差 1 ｜ `.mcu-discover-body` gap 10→6px / padding 12px 14px 10px → 8px 14px 6px

**复核结论：✅ 接受**

| 维度 | 评估 |
|---|---|
| 取舍依据 | 按指令值实测溢出 26px，违反平台「无溢出」硬规范 |
| 设计判断 | 6px gap 在 324px 高卡片中是合理折衷 |
| 优先级原则 | 平台硬规范 > 设计建议，排序正确 |
| 视觉影响 | 紧凑但不窒息，理由区与片名层仍保持视觉分组 |

**备注**：无需回调。

---

### 偏差 2 ｜ `.mcu-discover-reason` padding-top 8→2px

**复核结论：⚠️ 接受（有条件）**

| 维度 | 评估 |
|---|---|
| 取舍依据 | 为闭合溢出让位 |
| 设计判断 | 2px 偏紧，理由区与上方元信息行的呼吸感不足 |
| 接受前提 | 当前版本（360px / 414px 双尺寸实测）已通过验收，视觉影响可接受 |

**改进建议**（不阻塞本次上线）：
- 若 V1.2 迭代中画布区有空间冗余（例如压缩 hero 高度、精简元信息行），建议将 `padding-top` 回调至 **4px**
- 4px 是「分隔但同组」的最小呼吸感阈值

**备注**：列入 V1.2 候选优化项，不影响本次提审。

---

### 偏差 3 ｜ `.mcu-discover-reason-text` 3 行 → 2 行截断

**复核结论：✅ 接受**

| 维度 | 评估 |
|---|---|
| 取舍依据 | 324px 下 3 行会挤压底部提示条 |
| 设计判断 | 2 行更聚焦，符合"3 秒抓重点"的 GenUI 场景目标 |
| 用户价值 | 完整推荐理由在数据层保留，未来如需展开可加"展开更多"交互 |

**备注**：V1.0 设计稿原本就是 2-3 行弹性截断，2 行是合规范围内。

---

### 偏差 4 ｜ `.mcu-discover-hero` 高度 34%→40% / min 62px→80px

**复核结论：✅ 接受**

| 维度 | 评估 |
|---|---|
| 取舍依据 | 34%/62px 在海报上仅剩一条横带，失去视觉焦点 |
| 设计判断 | 40%/80px（360px 实测 81px / 414px 实测 103px）在 1:1 卡片中视觉比例更平衡 |
| 用户价值 | 海报是核心视觉资产，面积保障 > 文字区紧凑 |

**备注**：这一调整方向正确，符合"电影海报是首要识别要素"的设计原则。

---

### 偏差 5 ｜ 移除独立的「今日发现」徽章行

**复核结论：✅ 接受（结构性减法）**

| 维度 | 评估 |
|---|---|
| 取舍依据 | 该行占 33px，是压缩 hero 至 48px 的直接原因 |
| 设计判断 | V1.0 的「今日发现」徽章在紧凑画布下确实多余，属设计稿自身的过度设计 |
| 信息完整性 | "发现"语义已由卡片整体形态承载，年份信息在元信息行保留，无信息丢失 |

**设计侧自我修正记录**：V1.0 中 `.mcu-discover-badge-row` 是为了强化"发现卡"氛围，但在 324px 实测下成为空间挤压源。本次减法应记入设计稿 V1.1 修订说明，作为后续设计的反面案例。

## 2. 取舍原则认可

开发 AI 在 10.3 节的取舍逻辑完全成立：

> **平台硬规范（无溢出 / 无截断 / 无重叠）> 设计建议**

这是正确的优先级排序。设计稿 V1.0 / V1.1 的间距字面值是基于"理想状态"给出的建议，实际落地时必须服从 1:1 卡片在 324px / 388px 高度下的硬约束。

**沉淀到设计规范**：

**`genui-app-tools/extract-design-css.cjs` 需增加白名单保护**，以下 CSS 属性不得被抽取脚本清空：

```js
// 建议加入抽取脚本的"保护属性"白名单
const PROTECTED_PROPERTIES = [
  'position',      // 定位上下文
  'overflow',      // 溢出控制（absolute 子元素裁剪必需）
  'z-index',       // 层叠上下文
  'inset',         // 快捷定位
  'top', 'right', 'bottom', 'left'  // 偏移定位
];
```

**风险**：若工具层不加固，下轮设计稿 V1.2 / V2.0 更新时同类缺陷会复现。

**必须提醒的限制**：加固后的 `apply-design-css.cjs` **不可直接重跑产物**——其输入是设计稿
