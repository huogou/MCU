| `.v2-topic` 区块 | `padding: 18px var(--page-x) 16px`；PC（≥1024，与 v2.css 首页 PC 断点一致）：内部卡片 `max-width: 1280px; padding: 22px 40px`，与 `.v2-hero-inner` 内容列同宽（原稿 760px 为笔误，2026-10-13 裁决按设计稿执行，见第八节） |

| `.v2-topic-tag` 标签胶囊 | 复用 `.v2-hero-badge` 语法：`padding: 5px 12px; background: var(--gold-a10); border: 1px solid var(--gold-a20); border-radius: var(--r-full); font-size: var(--fs-mini); color: var(--gold); letter-spacing: .06em`；`i` 为 5px 金圆点 |
| `.v2-topic-title` | `22px / 700 / line-height 1.3 / margin: 10px 0 12px`；金渐变文字同 `.v2-hero-title` 写法（`text-main → gold-light → gold`，background-clip） |

| `.v2-topic-date` 日期块 | `flex: 0 0 112px; text-align: right`；`.v2-topic-date-d`：`22px / 700 / var(--gold) / serif 字体栈（var(--font-display)）/ line-height 1.1`；`.v2-topic-date-en`：`11px / var(--gold-light) / letter-spacing .14em / margin-top 6px` |
| 左栏 | `flex: 1 1 auto; min-width: 0` |

### 响应式

- **390 / 375（主基准）**：双栏横向，`gap: 14px`；左栏弹性、右栏固定 112px；副文案最多 2 行。
- **< 375 极端（360 实测兜底）**：不变布局（右栏仍 112px），副文案截断保护用 `overflow-wrap`，不裁剪。
- **430**：双栏同 390。
- **PC（≥1024）**：卡片与首页内容列同宽（max-width 1280 + padding 0 40px，对齐 `.v2-hero-inner`），gap 24px，左右栏比例约 3:1。
- 防溢出：卡片内容单行金线/标签不换行（white-space: nowrap）；`v2-topic-sub` 允许换行不截断（white-space: normal）。
