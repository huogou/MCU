【两处必要的守卫修复（属第 三 节完整性，非全局盲替换）】
1) pages/route-detail/route-detail.js:60
   原（混合态，抖音端会失效）：if (wx && wx.setNavigationBarTitle) tt.setNavigationBarTitle(...)
   改：if (tt && tt.setNavigationBarTitle) tt.setNavigationBarTitle(...)
   原因：调用已为 tt. 但守卫仍检查 wx，抖音端 wx 未定义→守卫恒假→标题永不设置。
2) app.js:14  onLaunch 云初始化守卫
   原：if (!wx.cloud) { ...; return; }
   改：if (typeof wx === 'undefined' || !wx.cloud) { ... }
   原因：抖音端 wx 未定义，原写法 `!wx.cloud` 抛 ReferenceError 致整个小程序启动崩溃。
   该改法仅做判空防崩溃，未创建任何生产后端接口（不违反第 五 节禁止项）。
