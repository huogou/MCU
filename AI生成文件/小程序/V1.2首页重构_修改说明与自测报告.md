## 一、修改说明

### 1. 目标
把首页从「小程序功能工具」调整为「陪用户探索漫威宇宙的观影助手」入口，固定六模块结构。

### 2. 固定六模块结构（自上而下，禁删）
| # | 模块 | 内容 |
|---|------|------|
| ① | 品牌区域 | MCU观影导航 / 你的漫威宇宙旅程 |
| ② | 继续观看卡 | 新人：从钢铁侠开始 / Phase 1 / 开始观看；老用户：当前观看进度(已看X/59) / 下一部电影(recommend.next) / 继续观看 |
| ③ | 我的路线 | 当前路线名 / 完成进度(已完成X/Y部) / 下一部推荐(路线内首个未看) |
| ④ | 宇宙探索入口 | 时间线 / 角色关系 / 阵营探索（统一入口行式） |
| ⑤ | 热门角色 | 角色 / 关联作品数量 / 查看故事线（点击进角色详情） |
| ⑥ | 最近观看 | 最近 6 部（横向卡片） |

### 3. UI 规范落地（作用域覆盖，不污染其他页面）
- 背景 `#080B12` / 一级卡片 `#161D2B` / 强调金 `#F2B233`（仅用于 开始/继续/当前推荐 按钮与强调文字）。
- 字体（px→rpx，375pt 基准 1px=2rpx）：标题 48 / 模块标题 36 / 卡片标题 34 / 描述 28 / 辅助 24。
- 间距：页面边距 32 / 模块间距 48 / 卡片内边距 32；圆角 32。
- 阶段色 `poster-pN` 沿用全局 phase token（规范未重定义）。

### 4. Icon 统一策略
- 全部入口采用统一「标记 + 标题 + 描述 + 箭头」行式，**不使用默认微信组件、不混用图标库**。
- 探索入口标记用统一字型（◷ 时间线 / ✦ 角色关系 / ◈ 阵营探索），与探索页既有字型风格一致。
- 阶段色头像用「首字徽章」（全局既有方案）。
- ⚠️ 待确认：当前仓库仅含 tab 类 PNG（home/routes/explore/my-mcu/star），无独立的 时间线/关系/阵营 icon 资源；本报告采用统一字型标记作为临时统一方案，待设计提供正式 icon 资源后替换。

### 5. 改动文件
| 文件 | 性质 | 说明 |
|------|------|------|
| `pages/home/home.wxml` | 结构重写 | 六模块（③我的路线 ④宇宙探索 ⑤热门角色 均按新规范） |
| `pages/home/home.wxss` | 样式重写 | V1.2 调色板作用域覆盖 + 全 Token 化；新增 my-route / explore-entry / hotChars 故事线样式 |

## 三、当前页面与旧版差异说明

### 1. 与 V1.1（旧双态）差异
| 维度 | V1.1 | V1.2 当前 |
|------|------|-----------|
| 形态 | 工具页，结构随进度大切换（新用户态/老用户态完全不同） | 固定六模块，双态仅影响继续观看卡文案 |
| 继续观看 | 老用户=旅程状态卡+进度环canvas+下一站推荐卡 | 老用户=下一部电影(recommend.next)+当前观看进度 |
| 路线模块 | 仅「新手路线推荐」(newcomer 名称+计数+开始体验) | 「我的路线」=当前路线+完成进度+路线内下一部推荐 |
| 快捷入口 | 新手入坑/宇宙探索/我的MCU（3 tab 入口） | 「宇宙探索入口」=时间线/角色关系/阵营探索（3 探索子入口） |
| 热门角色 | 仅展示头像+关联数 | 头像+关联数+「查看故事线」可进角色详情 |
| 视觉 | 全局 Token（#0B0E14/#141925/#E9A93B） | V1.2 作用域（#080B12/#161D2B/#F2B233）+ 统一字型入口 |

### 2. 与上一轮 V1.2 半成品差异（本轮相对 10:22 提交 a81ee5d 的调整）
- ③ 由「新手路线推荐」改为「我的路线」（反映用户当前路线与进度、路线内下一部）。
- ④ 由「三 tab 快捷入口」改为「宇宙探索入口」（时间线/角色关系/阵营探索）。
- ② 老用户由「latest 上次观看」改为「recommend.next 下一部电影」。
- ⑤ 新增「查看故事线」可点击进角色详情。
- 品牌副标题：找到属于你的漫威观影路线 → 你的漫威宇宙旅程。
