## 三、WXSS 结构

- 页容器 `.home-page`：`padding: var(--space-2xl) var(--page-x)`（顶/底 64rpx，左右 32rpx），背景 `var(--bg)`。
- 模块统一间距 `margin-bottom: var(--space-xl)`（48rpx）。
- 全部颜色/字号/间距引用 `var(--xxx)`，**组件规则零裸 hex**（已 grep 验证）。
- 卡片消费全局三级类，页面仅做级联微调（如 Hero 追加金色微渐变 + 金边框）。
- 阶段色仅用于海报/头像背景（`.poster-p1~p6`），不进入 UI 框架。

## 六、改造方案（Step 2 路线）— 含规范冲突披露

⚠️ **关键冲突：Step 2 指令以《首页高保真设计稿》为权威，但当前代码按《首页重设计方案》实现，两文档在多处数值不一致。** 以下为「当前实现（重设计方案）」与「高保真设计稿」的具体差值，若以高保真为准则需在 Step 2 调整：

| 维度 | 当前实现（重设计方案） | 高保真设计稿 | 若以高保真为准是否需改 |
|------|----------------------|-------------|----------------------|
| ① 品牌标识 | `clip-path` 盾牌，`gold-a20` | 金色竖条 10×64rpx，**无图标** | 是 |
| ④ 宇宙探索布局 | 横向等分 3 卡，仅图标+名称 | **纵向全宽**，图标+名称+**右箭头** | 是（布局+补箭头） |
| ⑤ 角色卡宽 | 200rpx | 156rpx | 是 |
| ⑤ 角色头像 | 64rpx | 88rpx | 是 |
| ⑤ 故事线字号 | 20rpx / 500 | 24rpx / 400 | 是 |
| ⑥ 最近观看间距 | 16rpx（space-sm） | 24rpx | 是 |
| ⑥ 最近观看名字 | 20rpx（mini） | 24rpx（caption） | 是 |
| ③ 我的路线 next-name | `text-main` | `gold` | 是 |
| ② Hero CTA 字号 | 34rpx（title） | 28rpx（body） | 冲突（高保真 vs 设计系统 §8 矛盾） |
| ② movie-name 字重 | 600 | 700（高保真新人态） | 冲突（高保真 vs 设计系统 §4 矛盾） |

> 说明：高保真设计稿与设计系统（Design System）本身也存在冲突（如 CTA 字号、movie-name 字重），需在确认权威源时一并裁定。

**Step 2 改造方案（待权威源确认后执行）：**
1. 锁定单一权威规范（高保真 or 重设计方案 or 设计系统，三选一裁定）。
2. 按上表逐条校准 10 处差值。
3. 探索入口 Icon 在 SVG 资源到位前维持 Unicode 占位（§5.2.3 许可）。
4. `home.js` 全程零改动。
