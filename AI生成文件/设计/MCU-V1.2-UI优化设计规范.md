# MCU V1.2 UI 优化设计规范

> 版本：V1.2-calibration · 2026-08-25
> 设计：QoderWork CN（设计AI）
> 状态：待策划AI（GPT）确认
> 效力：本规范为《MCU-V1.2-UI-Design-System-Final.md》的迭代升级，不替代其整体架构，仅调整视觉参数。

---

## 一、问题诊断

真机测试暴露的五个核心问题及其根因：

| 问题 | 表现 | 根因 |
|------|------|------|
| 字体层级不足 | 页面标题、模块标题、卡片标题视觉差异小，用户无法快速区分信息层级 | 5级字号间距过密（34→28仅6rpx），模块标题与卡片标题同尺寸 |
| Icon风格不统一 | 首页用Unicode占位符(◷✦◈)、电影详情用CSS三角、角色用文字首字、全景图用阶段色块 | 没有统一的图标视觉语言，四种风格混用 |
| 卡片密度过高 | 角色卡4行信息挤在156rpx宽、角色图鉴卡5行信息、电影详情模块密集 | 内边距偏小、信息未做取舍、缺少视觉呼吸感 |
| 页面留白不足 | 模块间呼吸感不够，整体感觉"满"和"赶" | 模块间距48rpx在真机上偏紧，卡片间距偏小 |
| 部分模块不像正式产品 | 品牌区=竖条+文字、探索入口=列表行、角色头像=纯色圆圈 | 视觉语言过于"系统设置"，缺少产品性格和品质感 |

## 二、字体规范（升级）

### 2.1 核心变更：拉开层级差距

旧体系的根本问题：34rpx（标题）和28rpx（正文）只差6rpx，真机上几乎无感。需要让每个层级"一眼可辨"。

新6级字号体系：

| 层级 | Token | 旧值 | 新值 | 变化 | 用途 |
|------|-------|------|------|------|------|
| Display | --fs-display | 48rpx | **56rpx** | +8 | 页面标题（品牌区、全景图、角色图鉴） |
| Display-Sm | --fs-display-sm | 40rpx | **44rpx** | +4 | 次级大标题（电影详情标题、角色详情标题） |
| Title | --fs-title | 34rpx | **36rpx** | +2 | 模块标题（"继续观看""宇宙探索""热门角色"） |
| Body | --fs-body | 28rpx | **26rpx** | -2 | 正文/卡片标题/按钮文字 |
| Caption | --fs-caption | 24rpx | **24rpx** | 不变 | 辅助说明/标签 |
| Mini | --fs-mini | 20rpx | **22rpx** | +2 | 极辅助（进度标签、时间标注） |

### 2.2 四级视觉层级定义

这是本次校准的核心——让每一屏内容都有清晰的阅读节奏：

**一级 · 页面标题**
- 字号：56rpx（--fs-display）
- 字重：700
- 颜色：--text-main
- 用途：品牌区主标题、各页面顶部标题
- 视觉感受：进入页面第一眼看到的锚点

**二级 · 模块标题**
- 字号：36rpx（--fs-title）
- 字重：600
- 颜色：--text-main（不再用--text-sub，模块标题需要有存在感）
- 用途：Hero Card 内的"继续观看"、"宇宙探索""热门角色""最近观看"
- 视觉感受：引导用户视线从上到下扫读

**三级 · 卡片标题**
- 字号：26rpx（--fs-body）
- 字重：600
- 颜色：--text-main
- 用途：卡片内部的核心信息（电影名、角色名、路线名）
- 视觉感受：比模块标题明显小，但仍然是信息焦点

**辅助 · 描述文字**
- 字号：24rpx（--fs-caption）或 22rpx（--fs-mini）
- 字重：400
- 颜色：--text-sub 或 --text-weak
- 用途：说明文字、进度、标签、元数据
- 视觉感受：安静退后，不抢焦点

### 2.3 字重规则（不变）

仅允许 400 / 600 / 700 三档。禁止 500。
- 400：正文、描述、辅助
- 600：标题、按钮
- 700：页面标题、品牌名、数字强调

## 三、色彩规范（微调）

### 3.1 色彩体系不变，仅补充氛围层

核心色板保持不变（--bg #080B12 / --surface-1 #161D2B / --gold #F2B233 等），不引入新色。

新增一个氛围 token：

| Token | 值 | 用途 |
|-------|-----|------|
| --surface-0 | #0D1119 | 页面底色微分层（用于 Hero 区背景、模块底色区分） |

目的：当前 --bg (#080B12) 和 --surface-1 (#161D2B) 之间跨度太大（明度差约8%）。加一个中间层 --surface-0 让 Hero 区、品牌区有微妙的"浮起感"，不用卡片也能区分区域。

### 3.2 金色使用克制原则

金色（--gold）是品牌强调色，当前使用量合理，但需明确：
- 金色实心填充：全页最多1处（CTA 按钮）
- 金色文字：用于关键数据（进度值、推荐片名）
- 金色边框：用于 hover 态和选中态
- 禁止：金色大面积铺底、金色用于非强调性装饰

## 四、间距规范（升级）

### 4.1 核心变更：给内容更多呼吸空间

旧间距在 DevTools 模拟器上看着合理，但真机屏幕偏小后显得拥挤。

新间距体系：

| Token | 旧值 | 新值 | 用途 |
|-------|------|------|------|
| --space-xs | 8rpx | **8rpx** | 不变（紧凑内间距） |
| --space-sm | 16rpx | **20rpx** | 卡片内元素间距 |
| --space-md | 24rpx | **28rpx** | 标题与内容间距 |
| --space-lg | 32rpx | **36rpx** | 模块内段落间距 |
| --space-xl | 48rpx | **56rpx** | 模块间距 |
| --space-2xl | 64rpx | **72rpx** | 页面顶部留白 |
| --page-x | 32rpx | **36rpx** | 页面左右边距 |

### 4.2 关键呼吸感指标

- 模块与模块之间：56rpx（旧48rpx），提升17%
- 页面顶部留白：72rpx（旧64rpx），提升12%
- 卡片内标题与内容：28rpx（旧24rpx），提升17%
- 页面左右边距：36rpx（旧32rpx），略增呼吸感

## 五、卡片规范（升级）

### 5.1 三级卡片体系调整

| 层级 | 旧圆角/旧内边距 | 新圆角/新内边距 | 用途 |
|------|----------------|----------------|------|
| Hero | 24rpx / 32rpx | **32rpx / 40rpx** | 全页焦点卡（继续观看、电影Hero） |
| Content | 16rpx / 24rpx | **20rpx / 28rpx** | 内容卡（我的路线、电影信息卡） |
| Compact | 12rpx / 16rpx | **16rpx / 20rpx** | 紧凑卡（探索入口行、角色卡） |

### 5.2 卡片密度控制规则

- 每张卡片内信息不超过3行核心内容（标题+描述+操作）
- 如果超过3行，考虑拆分为多张卡片或折叠次要信息
- 卡片之间间距不小于 20rpx（--space-sm）
- 卡片内文字行高统一 1.5（正文）或 1.3（标题）

### 5.3 首页角色卡瘦身

当前角色卡（156rpx宽）塞了4行：头像+名字+关联数+故事线入口。

优化方案：
- 保留：头像（放大到96rpx）、名字
- 下移：关联数和故事线入口合并为一行 "X 部 · 故事线 ›"
- 卡片宽度：156rpx → **168rpx**（略宽，减少文字截断）
- 卡片内边距：20rpx 12rpx → **24rpx 16rpx**

## 六、Icon 规范（重建）

### 6.1 问题

当前四种图标风格混用：
- Unicode 字符（◷ ✦ ◈ ›）—— 首页探索入口
- CSS 几何图形（三角、勾、箭头）—— 电影详情页
- 文字首字母（角色头像圆圈内的字）—— 角色体系
- 阶段色块（全景图节点顶部）—— 全景图

用户看到的是一个风格分裂的界面。

### 6.2 统一方向：线性图标 + 阶段色块

**功能性图标**（导航、操作、入口）：
- 风格：线性（描边），统一 2rpx 描边宽度
- 尺寸：48rpx × 48rpx（容器）/ 图标本体 36rpx 区域
- 颜色：默认 --text-sub，激活/强调态 --gold
- 圆角：与容器一致
- 具体图标清单：
  - 返回箭头（chevron-left）
  - 右箭头（chevron-right）
  - 播放三角（play）
  - 勾选（check）
  - 关闭（close/x）
  - 展开箭头（chevron-down）
  - 时间线图标（clock/timeline）
  - 关系图标（nodes/relations）
  - 阵营图标（shield/camp）

**内容标识**（角色头像、电影海报占位）：
- 保持阶段色渐变 + 首字母方案
- 但提升品质感：头像加 2rpx 半透明描边，字母字号适当缩小让留白更多
- 全景图节点保持阶段色块，但节点卡片内部排版优化（见第九节）

### 6.3 过渡方案

SVG 资源需要时间制作。在 SVG 就绪前：
- 功能性图标使用 CSS 绘制（已有 chevron/play/check/close 的 CSS 实现）
- 探索入口三个图标暂时保留 Unicode 占位，但统一放入 48rpx 方形容器中
- 不允许在新模块中使用新的 Unicode 图标

## 七、页面修改方案总览

### 7.1 首页（优先级最高）

| 模块 | 当前问题 | 优化方向 |
|------|---------|---------|
| 品牌区 | 金色竖条+文字，像系统设置页头 | 增大品牌标题字号至56rpx，副标题降至24rpx形成对比，竖条加粗到14rpx增加存在感 |
| 继续观看 Hero | 层级不够突出，卡片内信息平铺 | 电影名提升至36rpx/700，Phase信息降至22rpx/--text-weak，CTA按钮保持金色但增加微阴影 |
| 我的路线 | 与Hero卡视觉差距小 | 保持Content卡但减少信息量：路线名+进度条+下一部，Ghost按钮保留 |
| 宇宙探索 | 三行列表像设置菜单 | 图标容器放大到64rpx、加金色微渐变底色，行高增加到88rpx，右箭头统一CSS chevron |
| 热门角色 | 卡片拥挤、头像偏小 | 卡片加宽到168rpx、头像放大到96rpx、合并底部两行为一行 |
| 最近观看 | 海报占位色块感重 | 保持现有尺寸，增加海报圆角到16rpx、底部名字间距增大 |

### 7.2 角色图鉴页

| 问题 | 优化方向 |
|------|---------|
| 卡片信息5行太密 | 精简为3行：中文名+作品数 / 简介（1行截断）/ 阵营标签+首登场 |
| 头像88rpx偏小 | 放大到104rpx，增加阵营色描边存在感 |
| 阵营筛选chips太密 | 增大chips内边距（12rpx 28rpx → 16rpx 32rpx），选中态加粗底纹 |
| 整体像数据列表 | 卡片增加左侧阵营色竖条（4rpx宽），增加"图鉴"品质感 |

### 7.3 角色详情页

| 问题 | 优化方向 |
|------|---------|
| Hero区居中排列太"个人主页" | 改为左对齐布局：头像左置+信息右置，更像数据库详情页 |
| 关联作品行太密 | 行间距从20rpx增至28rpx，海报缩略图从72rpx增至80rpx |
| 关系网格3列太挤 | 保持3列但增大卡片内边距，关联角色头像从80rpx增至88rpx |
| 卡片标题用金色不够统一 | 卡片标题统一为 --text-sub + 600字重，不再用金色（金色留给数据强调） |

### 7.4 宇宙全景图

| 问题 | 优化方向 |
|------|---------|
| 节点文字和连线冲突 | 增大节点卡片尺寸（宽+10px、高+8px），节点内文字缩至20rpx |
| Phase标签与年份重叠 | Phase标签字号保持24rpx/700，年份降至18rpx，两者间距增至12rpx |
| 整体信息密度过高 | 默认只显示主线节点，支线节点缩小50%或降低透明度 |
| 图例区域太简陋 | 图例移到页面底部固定栏，增加说明文字 |

### 7.5 电影详情页

| 问题 | 优化方向 |
|------|---------|
| 标题层级不够清晰 | 电影名保持44rpx/700，Phase标签降至20rpx/--text-weak，chips统一22rpx |
| 标签体系混乱（chip+status+phase） | 统一标签高度：所有chip类元素高度一致（padding 6rpx 16rpx），圆角一致 |
| 模块间距偏小 | 各模块间距从32rpx增至40rpx（--space-lg新值） |
| CTA按钮字号过大 | CTA字号从36rpx降至32rpx（--fs-title），与按钮高度更匹配 |
| 资源模块展开态不够明显 | 展开时增加背景色微变（surface-2 → surface-2 加 gold-a04 底色） |

## 十、开发实现说明

### 10.1 变更范围

本次优化涉及两个文件的修改：

**app.wxss**（全局 Token 层）：
- 修改 6 个字号 Token 值
- 修改 6 个间距 Token 值
- 新增 1 个颜色 Token（--surface-0）
- 修改 3 个卡片类的 padding 和 border-radius

**各页面 .wxss**：
- 首页 home.wxss：模块标题颜色 --text-sub → --text-main、角色卡底部合并、探索图标容器放大、CTA 微阴影
- 角色图鉴 characters.wxss：头像放大、卡片加阵营色竖条、chips 内边距增大
- 角色详情 character.wxss：Hero 区改左对齐、卡片标题颜色调整、间距增大
- 全景图 panorama.wxss：节点尺寸调整、Phase 标签间距
- 电影详情 movie.wxss：模块间距增大、CTA 字号调整、标签统一

### 10.2 实施顺序

建议按以下顺序实施，每步可独立验收：
1. app.wxss Token 更新（全局生效，立即可见变化）
2. 首页 home.wxss（最高优先级页面）
3. 电影详情 movie.wxss（用户停留时间最长）
4. 角色图鉴 + 角色详情（联动修改）
5. 全景图 panorama.wxss

### 10.3 约束

- 不改页面结构（wxml 不变）
- 不改数据模型（js 不变）
- 不改跳转逻辑（js 不变）
- 不改 TabBar 结构
- 纯 CSS 视觉优化
