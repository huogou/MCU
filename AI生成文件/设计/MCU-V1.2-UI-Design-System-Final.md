## 一、全局设计规范

### 1.1 产品视觉定位

**定位语：深空影院中的金色叙事**

- 深空 = 深色背景营造的沉浸感（不是纯黑，是有层次的深蓝黑）
- 影院 = 电影感的视觉体验（宽呼吸、大字号、克制的信息密度）
- 金色 = 唯一的强调色，引导视线、标记重要信息
- 叙事 = 不是平铺数据，而是引导用户一步步探索

**产品气质：打开后像进入漫威宇宙控制中心，而不是打开了一个电影列表。**

### 1.2 三级视觉金字塔

```
        ┌─────┐
        │ 金色 │  ← 引导层：CTA按钮、选中态、品牌标识。占比 < 5%
        ├─────┤
        │ 文字 │  ← 信息层：标题白、描述灰、辅助浅灰。占比 ~25%
        ├─────┤
        │ 深空 │  ← 背景层：四级深色背景，营造沉浸画布。占比 ~70%
        └─────┘
```

### 1.3 设计原则

原则一：**少即是多。** 如果一个元素不能帮助用户决定"下一步看什么"或"接下来探索什么"，它就不应该出现在界面上。

原则二：**呼吸感优先。** 模块之间留足空间，让页面有"段落感"。宁可让用户多滑一次，也不要让页面看起来像一块密不透风的信息墙。

原则三：**金色克制。** `--gold` 是唯一的强调色。如果一个页面中有两个以上的高饱和色在"抢"用户注意力，说明设计出了问题。

原则四：**一致性即品质。** 所有页面使用同一套色彩、字号、间距、卡片规范。用户不应该在不同页面之间跳转时感受到风格跳跃。

### 1.4 风格禁区

- 禁止使用渐变背景作为大面积 UI 元素底色（海报占位和 Hero Card 除外）
- 禁止使用阴影（box-shadow）来建立层级——用色阶差异代替
- 禁止使用圆角超过 24rpx 的元素（除 Hero Card 外）
- 禁止使用动画时长超过 400ms 的动效
- 禁止使用弹跳（bounce）、旋转进入、闪烁等"活泼"动效
- 禁止在页面 WXSS 中写死 hex 颜色值——必须引用 CSS 变量

### 1.5 色彩系统

#### 背景层

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg` | `#080B12` | 页面底色。深空黑，微蓝偏冷 |
| `--surface-1` | `#161D2B` | 一级卡片 / Tab栏 |
| `--surface-2` | `#1E2636` | 二级卡片 / 内容区块 |
| `--surface-3` | `#2A3447` | 边框 / 分割线 / 交互态底色 |

色阶间距：每级亮度递增约 8-12%，层级感清晰但不过度对比。

#### 品牌色

| Token | 色值 | 用途 |
|-------|------|------|
| `--gold` | `#F2B233` | 主强调色。CTA按钮、选中态、品牌标识、进度指示 |
| `--gold-btn-text` | `#1A1206` | 金色按钮上的文字色（深色） |

#### 文字层

| Token | 色值 | 用途 | 对比度（vs `#080B12`） |
|-------|------|------|----------------------|
| `--text-main` | `#E8ECF4` | 标题、核心信息 | ≈14.5:1 |
| `--text-sub` | `#8E98AA` | 描述文字、次要信息、卡内标题 | ≈6.2:1 |
| `--text-weak` | `#555F73` | 辅助标签、禁用态 | ≈3.2:1 |

**文字颜色规则：** 字号越大越白，字号越小越灰。金色只出现在需要引导视线的位置。

#### 状态色

| Token | 色值 | 用途 |
|-------|------|------|
| `--success` | `#3FB98A` | 已观看、已完成 |
| `--error` | `#E5604D` | 错误、警告 |

#### 阶段色（仅用于内容标识）

| Token | 色值 | 阶段 |
|-------|------|------|
| `--p1` | `#5B8DEF` | Phase 1 |
| `--p2` | `#28B487` | Phase 2 |
| `--p3` | `#F0A932` | Phase 3 |
| `--p4` | `#8B6FE8` | Phase 4 |
| `--p5` | `#E8483F` | Phase 5 |
| `--p6` | `#C25B8E` | Phase 6 |

**阶段色使用规则：** 阶段色只出现在"内容本身"上（电影卡片左侧色条、角色头像背景、时间线节点），不出现在 UI 框架元素上（按钮、边框、图标）。

#### 金色透明度变体

| Token | 色值 | 用途 |
|-------|------|------|
| `--gold-a06` | `rgba(242,178,51,0.06)` | 金色微光背景（Hero Card 渐变起点） |
| `--gold-a10` | `rgba(242,178,51,0.10)` | 金色淡背景（chip、标签） |
| `--gold-a15` | `rgba(242,178,51,0.15)` | 金色轻背景（hover态） |
| `--gold-a20` | `rgba(242,178,51,0.20)` | 金色边框（选中态边框、Hero Card 边框） |
| `--gold-a40` | `rgba(242,178,51,0.40)` | 金色图标/装饰 |
| `--gold-a60` | `rgba(242,178,51,0.60)` | 金色次强调 |

#### 色彩使用纪律

规则一：所有颜色必须引用 CSS 变量（`var(--xxx)`），禁止在页面 WXSS 中写死 hex 值。

规则二：阶段色不参与 UI 框架，只标记内容归属。

规则三：`--gold` 是唯一的强调色。

规则四：`app.json` 中不能使用 CSS 变量，必须写死 hex 值，但这些值必须与对应 token 完全一致。

#### 需要废弃的 Token

| Token | 原因 |
|-------|------|
| `--line`（`#202938`） | 功能与 `--surface-3` 重叠 |
| 旧的 `--gold-a*` 系列（基于 `rgb(233,169,59)`） | 全部更新为基于 `rgb(242,178,51)` |
| `--p1-a60` 等阶段色 alpha 变体 | 统一使用 `rgba()` 内联写法，不单独定义 token |

### 1.6 字体系统

#### 字族

```css
font-family: -apple-system, "PingFang SC", "Helvetica Neue", Helvetica, sans-serif;
```

#### 字号层级（5级制）

| 层级 | Token | 字号 | 字重 | 行高 | 用途 |
|------|-------|------|------|------|------|
| Display | `--fs-display` | `48rpx` | 700 | 1.3 | 页面主标题、品牌标题。每页最多1次 |
| Title | `--fs-title` | `34rpx` | 600 | 1.4 | 模块标题、卡片标题 |
| Body | `--fs-body` | `28rpx` | 400 | 1.5 | 正文、描述文字、按钮文字 |
| Caption | `--fs-caption` | `24rpx` | 400 | 1.4 | 辅助信息、标签、时间戳 |
| Mini | `--fs-mini` | `20rpx` | 400 | 1.3 | 极小标注、阶段标记、chip内文字 |

**字重规则：** 全产品只使用 400（常规）、600（半粗，Title 及以上）、700（仅 Display 层级）。不使用 500。不使用 700 以上。

**变体：** `--fs-display-sm: 40rpx` 仅用于子页面标题（如电影详情页），Tab 页面统一 48rpx。

#### 文字颜色映射

| 层级 | 颜色 |
|------|------|
| Display / Title（模块标题） | `--text-main` |
| Title（卡内标题） | `--text-sub` |
| Body（正文描述） | `--text-sub` |
| Caption / Mini | `--text-weak` |
| 金色强调文字 | `--gold` |
| 阶段标识文字 | `--p1` ~ `--p6` |

**说明：** 模块级标题（独立于卡片之外的标题，如"宇宙探索""热门角色"）用 `--text-main`。卡片内部的标题（如 Hero Card 内的"继续观看"）用 `--text-sub`，让标题安静退后，把焦点留给卡片内容。

### 1.8 Icon 规范

#### 图标风格

线性图标（Outlined），1.5px 描边，圆角端点。与"档案馆"气质一致——精致、克制、不花哨。

禁止使用填充图标（Filled）作为功能图标。填充风格仅用于 Tab 栏选中态。

**禁止开发自行使用 Unicode 字符替代 SVG 图标。** Unicode 仅允许在 SVG 资源未就绪时作为临时占位，且必须在后续迭代中替换。

#### 图标尺寸

| 场景 | 尺寸 | 说明 |
|------|------|------|
| 模块入口图标容器 | `48rpx × 48rpx` | 探索页入口、首页快捷入口的图标容器 |
| 图标本体 | `28rpx × 28rpx` | 容器内的实际 SVG 图标尺寸 |
| 卡片内图标 | `36rpx × 36rpx` | 卡片中的功能标识 |
| 行内图标 | `28rpx × 28rpx` | 与文字同行的图标（如箭头） |
| 微型图标 | `24rpx × 24rpx` | chip内、标签内、CTA按钮内播放图标 |
| Tab 栏图标 | `48rpx × 48rpx` | 保持现有尺寸（81px PNG @3x） |

#### 图标颜色规则

| 场景 | 颜色 |
|------|------|
| 默认态 | `--text-weak` |
| 激活/选中态 | `--gold` |
| 品牌入口装饰 | `--gold` |
| 探索入口图标 | `--gold` |
| 阶段标识 | 对应 `--p1` ~ `--p6` |

#### SVG 规范

- 格式：SVG 文件，通过 `<image>` 引用或 base64 内联
- viewBox：统一 `0 0 28 28`（对应 28rpx 图标本体）
- 描边：`stroke-width: 1.5`，`stroke-linecap: round`，`stroke-linejoin: round`
- 填充：功能图标 `fill: none`；Tab 选中态可填充
- 颜色：通过 `stroke` 属性控制，不写死颜色值

#### Unicode 字符替换表

| 当前用法 | 替换为 SVG | 临时占位方案 |
|---------|-----------|------------|
| `◈`（宇宙全景/阵营） | 盾牌轮廓 SVG | `◈` 36rpx / `--gold` |
| `✦`（角色图鉴） | 人物/图鉴 SVG | `✦` 36rpx / `--gold` |
| `◷`（时间线/关系） | 时间线/连线 SVG | `` 36rpx / `--gold` |
| `›` / `»`（箭头） | chevron-right SVG | `›` 24rpx / `--text-weak` |
| `√`（成功） | check-circle SVG | `√` 24rpx / `--success` |
| `!`（错误） | alert-circle SVG | `!` 24rpx / `--error` |
| `★`（收藏） | star SVG | `★` 24rpx / `--gold` |

#### 三级卡片（Compact Card）

| 属性 | 规格 |
|------|------|
| 背景 | `var(--surface-2)` `#1E2636` |
| 边框 | 无 |
| 圆角 | `12rpx` |
| 内边距 | `16rpx 20rpx` |

#### 卡片交互态

| 状态 | 样式变化 |
|------|---------|
| 默认 | 如上定义 |

#### 卡片内容结构规范

一级卡片内部结构：
```

```

```

[左侧：海报/图标] ← 20rpx → [右侧：标题 (Title/600/--text-main) + 描述 (Caption/400/--text-weak)]
```

三级卡片内部结构：
```

    ↓ 16rpx
[名称 (Body/400/--text-main)]
```
