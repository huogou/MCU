## 一、验收方法

逐文件代码审查（wxml + wxss + js），对照 VDS V2 设计规范逐项验证：
- 图片资源是否真实接入（visuals.js 单一来源）
- 海报/剧照是否完整（38 部 CDN）
- 字体层级（5 档：Display 56 / Title 36 / Body 28 / Caption 24 / Mini 22）
- 页面间距（7 级 Token：xs/sm/md/lg/xl/2xl/page-x）
- Icon（纯 CSS 绘制，无第三方库）
- 圆角（5 级 Token：sm/md/lg/xl/full）
- Token 覆盖率（零裸 hex / 零 500·800 字重）
- 移动端排版（响应式 / scroll-x / 点击热区）
- 页面整体视觉一致性（暗色宇宙风 · 金色主线 · 蓝红紫功能色）
- 是否仍存在"纯文字资料库"感
