## 一、视觉方向总纲

### 1.1 核心问题

当前版本由文字和色块构成，用户感受不到漫威宇宙的存在。电影=阶段色块+首字，角色=彩色圆圈+首字，首页=功能入口列表，全景图=线条节点图。整体像数据管理后台，不像 MCU 产品。

### 1.2 目标

用户打开小程序 30 秒内感受到 **"这是漫威宇宙"** ——不是"这是一个工具"。

**视觉关键词**：暗黑宇宙 · 图片驱动 · 沉浸探索 · 金色主线

### 1.3 设计原则

1. **图片优先**：能用图片的地方不用文字，能用大图不用小图
2. **暗色画布**：深色背景是画布，让图片成为焦点
3. **金色克制**：金色只用于强调和引导，不铺面积。全页实心填充最多 1 处（主 CTA）
4. **功能四色**：金色主线 + 蓝(科技/信息) + 红(英雄/热血) + 紫(宇宙/神秘)
5. **优雅降级**：图片未加载时阶段色渐变兜底，不空白不破碎

### 1.4 色彩扩展（V1.2 新增）

在原有金色主线 + 阶段色基础上，新增三个功能强调色：

| Token | 值 | 语义 | 典型用途 |
|-------|-----|------|---------|
| --accent-blue | #4A9EF5 | 科技/信息 | 时间线入口、信息标签、盟友关系 |
| --accent-red | #E85D5D | 英雄/热血 | 复仇者阵营、英雄高亮、敌人关系 |
| --accent-purple | #9B7FE8 | 宇宙/神秘 | 多元宇宙标识、宇宙力量、家人关系 |

使用规则：四色（gold/blue/red/purple）用于功能强调，不用于背景或大面积填充。

## 二、首页 — "我的 MCU 宇宙入口"

### 2.1 设计理念

首页不是功能入口列表。用户打开的第一秒应该感受到：我在漫威宇宙里，我知道自己看到哪了，我知道下一步看什么，我可以探索更多。

### 2.2 页面结构

```
┌──────────────────────────────────────┐
│                                      │
│  ① MCU 旅程进度卡                    │  ← 核心身份感
│     "我的 MCU 旅程 · 18/59"          │
│     当前电影海报 + Phase              │
│                                      │
│  ② 推荐下一部（大卡）                │  ← 核心行动点
│     大电影海报 + 片名 + 理由 + CTA    │
│                                      │
│  ③ 宇宙入口（3 个视觉卡片）          │  ← 探索导航
│     时间线 / 角色图鉴 / 关系探索      │
│                                      │
│  ④ 热门角色（横向滚动）              │  ← 角色吸引力
│     真实头像 + 名字 + 阵营            │

│  ⑤ 最近观看（横向滚动）              │  ← 历史记录

## 五、宇宙全景图 — 阶段旅程

从"自由画布节点图"改为"按阶段分区的纵向时间线"，每个阶段有视觉氛围，像一段穿越 MCU 阶段的旅程。

### 5.2 页面结构

```
┌──────────────────────────────────────┐
│  宇宙全景图            ← 56rpx/700   │
│  从大爆炸到多元宇宙                   │
│                                      │
│  ╔══════════════════════════════════╗│

## 十、验收标准

1. **图片覆盖**：所有海报位、头像位、背景位显示真实图片（非色块首字）
2. **加载体验**：图片加载中显示阶段色渐变，不出现空白或 broken icon
3. **降级兜底**：图片加载失败回退到阶段色渐变 + 首字
4. **旅程感**：首页进度数字醒目（金色 56rpx），用户一眼看到"我在 MCU 的位置"
5. **行动明确**：推荐大卡是全页视觉焦点，CTA 引导清晰
6. **探索吸引**：三个入口卡片有各自氛围色（蓝/红/紫）
7. **层级清晰**：进度数字(56rpx) > 模块标题(36rpx) > 电影名(28rpx) > 描述(24/22rpx)
8. **视觉一致**：所有图片圆角、边框风格统一
9. **性能**：首屏加载不卡顿，图片 lazy-load 正常
10. **双态正确**：新人态和老用户态显示不同内容
