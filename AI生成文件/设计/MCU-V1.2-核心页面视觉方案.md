## 一、电影详情页

### 1.1 设计理念

电影详情页不能是资料页。它应该像一张电影票——让人想立刻"入场"。

### 1.2 页面结构

### 1.3 关键规格

| 元素 | 规格 |
|------|------|
| 背景图区 | 750×500rpx，电影海报模糊或场景图，叠加阶段色渐变 |
| | 渐变：linear-gradient(to bottom, --p{N}-a20 0%, --bg 100%) |
| 海报 | 220×320rpx，圆角 16rpx，border 4rpx --gold-a20 |
| | 真实海报图，兜底阶段色渐变+首字 |
| 电影名 | 36rpx / 700 / --text-main |
| 英文名 | 24rpx / 400 / --text-sub |
| Phase + 年份 | 22rpx / 400 / --text-weak |
| Chips | 22rpx / --text-weak，胶囊 --surface-3 底 |
| 状态标签 | 22rpx / 600，未看=--gold/--gold-a10，已看=--text-weak/--surface-3 |
| CTA | 全宽，88rpx 高，--gold 底，--glow-gold |
| 推荐理由卡 | --surface-2 底，圆角 20rpx，padding 28rpx |
| | 标签 24rpx / 600 / --accent-blue（蓝色=信息） |
| | 正文 28rpx / --text-sub，line-height 1.7 |
| 前后关联 | 3 列等分，海报 80×120rpx |
| | 当前卡片高亮：--gold-a10 底 + --gold-a20 边框 |
| | 箭头 CSS chevron |
| 主要角色（新增） | 横向 4 个头像，80rpx 圆形 |
| | 来自 content.chars 字段取前 4 位 |
| | 点击跳转角色详情 |

### 1.4 与上一版差异

- 新增"主要角色"模块（从 content.chars 取前 4 位角色头像）
- 推荐理由标签颜色从 --gold 改为 --accent-blue（蓝色=信息性内容）
- 背景图从纯色改为阶段色渐变（更有电影氛围）

## 二、角色详情页

### 2.1 设计理念

角色详情页应该像漫威官方角色图鉴——打开就能感受到这个角色的"气场"。

```
│                                      │
│  ┌──────┐                            │
│  │[头像] │  钢铁侠                   │  ← 128rpx 真实头像
```

## 三、宇宙关系探索页

### 3.1 设计理念

这是 MCU 小程序的核心特色——展示角色之间的关系网络。

V1.2 分两步：
- **第一步（本次）**：将现有列表中的文字头像替换为真实角色头像照片，保持现有 Canvas 关系图
- **第二步（V1.3 远期）**：重新设计关系网络可视化

### 3.2 V1.2 页面结构

```
┌──────────────────────────────────────┐
│  关系探索               ← 56rpx/700  │
│  MCU 角色关系网络                     │
│                                      │
│  [关系类型筛选]                       │
│  [全部] [盟友] [敌人] [师徒] [家人]  │
│                                      │
│  ┌──────────────────────────────┐    │
│  │  [头像] ←────→ [头像]        │    │  ← 关系对
│  │  钢铁侠    盟友    美队       │    │
│  │  复仇者           复仇者      │    │
│  │  共同出演 12 部               │    │
│  └──────────────────────────────┘    │
│                                      │
│  ┌──────────────────────────────┐    │
│  │  [头像] ←────→ [头像]        │    │
```

### 3.3 关系卡片规格

| 元素 | 规格 |
|------|------|
| 关系卡 | --surface-2 底，圆角 20rpx，padding 28rpx |
| | 间距 20rpx |
| 左角色 | 头像 80rpx 圆形（真实照片）+ 名字 24rpx/600 + 阵营 22rpx |
| 关系类型 | 居中，22rpx / 600 |

| 右角色 | 同左角色 |
| 共同出演 | 22rpx / --text-weak，底部居中 |

| 关系类型 | 颜色 | Token |
|---------|------|-------|

| 敌人 | 红色 | --accent-red |

| 家人 | 紫色 | --accent-purple |

| 状态 | 样式 |
|------|------|
| 默认 | --surface-2 底，--text-sub 文字，--surface-3 边框 |

## 五、开发实施说明

### 5.1 电影详情页改动

- wxml：Hero 区增加背景图 image + 新增"主要角色"模块
- wxss：Hero 区背景渐变样式、角色头像样式
- js：从 content.chars 取前 4 位角色 ID，注入角色头像 URL

### 5.2 角色详情页改动

- wxml：Hero 区增加背景图 image、头像改为 image、海报改为 image
- wxss：背景图样式、阵营色渐变映射
- js：注入角色背景图 URL、关联作品海报 URL

### 5.3 关系探索页改动

- wxml：关系对中的文字头像改为 image
- wxss：关系类型颜色映射
- js：注入角色头像 URL

### 5.4 实施优先级

1. P0：电影详情页（海报+背景图+角色头像）— 用户停留最久
2. P0：角色详情页（头像+背景图+海报）— 角色体系核心
3. P1：关系探索页（头像替换）— 改动小，效果明显
