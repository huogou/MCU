## 六、远程托管待办（防电脑重装/硬盘损坏的关键）

本地 Git 仓库只能本地回滚，**无法防硬盘损坏**。要实现真正的异地容灾，需任选其一配置远程：

| 方案 | 操作 | 说明 |
| --- | --- | --- |
| GitHub | 连接 `github` 连接器 或手动建仓库后 `git remote add origin <url>` + `git push` | 通用，需账号 |
| Gitee 码云 | 手动建仓库 + push | 国内访问快 |
| CloudBase 云存储 | 将 `mcu-navigator/` 等打包上传环境 `mcu-d6gw0brqoa9521b58` | 已有环境，可脚本化 |

**建议**：确认后我立即执行 `git remote add` + `git push`，并在 `backup/版本记录.md` 回填远程地址。
