## D-20260928-02 · 载体形态（已澄清 · 官方定义）

- **结论**：载体 = **小红书小工具容器**——运行在小红书 App 沙箱内的纯本地 Web 应用（HTML / CSS / JS），由平台自动注入端能力 SDK（`window.xhs.miniTool`）。

## D-20260928-03 · 「离线」语义（已澄清 · 官方定义）

- **结论**：「离线」= 官方定义的**纯本地运行、不联网、资源全打包**。小工具不支持任何网络请求，所有页面/脚本/图片/字体/数据必须内置。
- **依据**：官方指南 §01「离线：本地运行、不联网」+ §04.2「已禁用的行为：网络请求 fetch/XHR、外部图片/字体/媒体」。
- **影响**：数据方案「构建期内置快照」由可选项升级为**强制项**；任何运行时拉取数据的设想被否定。
- **状态**：✅ 已澄清。置信度：高。

## D-20260928-04 · 分享卡片（F4）机制与规范（已澄清）

- **生成机制**：客户端 Canvas 2D 渲染卡片位图 → `writeTempFile`(base64→本地 filePath) → 二选一：
  - `saveImageToPhotosAlbum`：保存图片到系统相册；
  - `postNote`：唤起笔记发布页（图文，title≤20 字、content≤1000 字、图片 1–18 张、支持 `data:` base64 或本地路径）。
- **硬约束**：卡片标题 **≤20 字**（由 `postNote.title` 上限锁定）；媒体字段不接受 `http(s)://` 网络地址。
- **视觉规范**：卡片布局须可由 Canvas 程序化渲染（坐标 / 字号 / 图层），由设计 AI 阶段3 在 `设计规范.md` §3 提供。
- **状态**：✅ 机制已澄清；视觉细则待阶段3。置信度：高（机制）/ 中（视觉细则）。

## D-20260928-05 · 关键技术约束（影响阶段4/5/6）

- **网络**：禁用 `fetch` / `XMLHttpRequest` / WebSocket / SSE / 外链资源。所有资源打包内置。
- **脚本**：必须外置（`<script src="./x.js">`）；禁内联 `<script>`、禁 `onclick=` 等行内事件、禁 `eval()` / `new Function()`、禁 WebAssembly、禁 Web Worker / Service Worker、禁 `iframe`、禁 `window.open` / `target="_blank"`。事件绑定用 `addEventListener`。
- **样式**：`<style>` 与 `style=""` 均可用，可内联。
- **资源白名单**：`.html/.css/.js/.png/.jpg/.jpeg/.gif/.webp/.svg/.woff/.woff2/.json`。
- **图形**：Canvas 2D 完整支持（F4 主路径）；WebGL 可用但禁 WASM/Worker/外部纹理。
- **存储**：`localStorage` / `sessionStorage` / `IndexedDB` / Cookie（仅本地）可用，按小工具隔离。
- **端能力**：`window.xhs?.miniTool` 判空 + 降级路径；未列出的 API 一律不可用。
- **包体积上限**：本次官方指南提取**未给出明确 MB 数值** → 阶段6 提交前须核实最新限制（见 T2-06）。
- **状态**：✅ 已记录。置信度：高（约束）/ 低（包体积具体值待核实）。
