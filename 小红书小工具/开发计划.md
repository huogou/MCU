## 5. 阶段5 技术栈约束（来自 D-20260928-05）

- 标准 HTML / CSS / JS；脚本必须外置 `<script src>`，禁内联 / 禁 `onclick` / 禁 `eval` / WASM / Worker / iframe。
- 不依赖任何联网 CDN、不引入需运行时的重型框架；如用第三方库，须确认其不依赖 `eval`/WASM/Worker 且可离线打包。
- F4 卡片：Canvas 2D 渲染（WebGL 可用但禁 WASM/Worker，重计算不可行）。
