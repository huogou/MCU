MCU 观影导航 H5 —— 阿里云轻量服务器部署步骤
生成时间：2026-09-07
部署包：workspace/deploy/mcu-h5.tar.gz（121 文件 / 13MB）
配置模板：workspace/deploy/nginx-mcu-h5.conf

说明：以下步骤全部为「新增」，不修改、不覆盖、不删除博客任何文件与配置。


==========================================================
第一阶段：服务器环境检查（只读，不改任何东西）
==========================================================

  cat /etc/os-release                          # 操作系统
  nginx -v                                     # Web 服务与版本
  systemctl status nginx                       # Nginx 运行状态
  cat /www/server/panel/vhost/nginx/*.conf     # 看现有站点配置（找博客目录和域名）
  ls /www/wwwroot/                             # 现有站点目录
  nginx -T 2>/dev/null | grep -E "server_name|root "   # 列出所有站点域名与根目录
  df -h                                        # 剩余磁盘
  ss -tlnp | grep -E ":80|:443"                # 80/443 端口占用
  ls /www/server/panel/vhost/cert/             # 现有 SSL 证书（若有）

  重点记录：
    - 博客目录（如 /www/wwwroot/blog）
    - 博客域名（如 example.com）
    - Nginx 站点配置目录（宝塔：/www/server/panel/vhost/nginx/）
    - 是否装了宝塔（bt 命令是否存在）


==========================================================
第二阶段：创建独立 H5 目录 + 上传（不影响博客）
==========================================================

  # 1. 建独立目录（与博客目录平级，绝不放在博客目录内）
  mkdir -p /www/wwwroot/mcu-h5

  # 2. 上传部署包（二选一）
  #    方式 A：本机 scp（在你自己电脑上执行）
  #    scp workspace/deploy/mcu-h5.tar.gz root@<服务器IP>:/tmp/
  #
  #    方式 B：服务器上直接下载（若已传到对象存储/GitHub）

  # 3. 解压（在服务器上执行）—— 注意 --strip-components=1，直接铺到 mcu-h5 根
  tar -xzf /tmp/mcu-h5.tar.gz -C /tmp
  cp -a /tmp/h5/. /www/wwwroot/mcu-h5/

  # 4. 校验文件数（应为 121）
  find /www/wwwroot/mcu-h5 -type f | wc -l

  # 5. 权限（Nginx 运行用户，宝塔通常是 www）
  chown -R www:www /www/wwwroot/mcu-h5
  find /www/wwwroot/mcu-h5 -type d -exec chmod 755 {} \;
  find /www/wwwroot/mcu-h5 -type f -exec chmod 644 {} \;

  # 6. 确认博客目录未被触碰
  ls -la /www/wwwroot/


==========================================================
第三阶段：DNS（在域名解析服务商处操作，不是服务器）
==========================================================

  新增一条解析记录，不要动博客现有记录：

    类型：A
    主机记录：mcu
    记录值：<阿里云轻量服务器公网 IP>
    TTL：默认（10 分钟）

  生效检查（本机执行）：
    nslookup mcu.你的域名.com
    # 或
    ping mcu.你的域名.com

  注意：若域名已在阿里云且服务器在大陆，主域名应已完成 ICP 备案，
        新增子域名通常无需重新备案。若主域名未备案，请务必先确认。


==========================================================
第四阶段：Nginx 独立站点配置
==========================================================

  # 1. 复制配置模板，替换其中的 mcu.example.com 为真实子域名
  #    放到与博客同级的站点配置目录（宝塔）：
  #    /www/server/panel/vhost/nginx/mcu-h5.conf

  # 2. 检查语法（这一步不会重载，安全）
  nginx -t

  # 3. 平滑重载（不影响正在运行的博客）
  nginx -s reload
  # 或 systemctl reload nginx


==========================================================
第五阶段：HTTP 测试（先不通 HTTPS）
==========================================================

  curl -I http://mcu.你的域名.com/
  curl -I http://mcu.你的域名.com/next.html
  curl -I http://mcu.你的域名.com/assets/css/style.css
  curl -I http://mcu.你的域名.com/assets/js/app.js
  curl -I http://mcu.你的域名.com/data/movies.js
  curl -I http://mcu.你的域名.com/assets/posters/iron-man.jpg

  全部应为 200，且 .html 路径直返 200（Nginx 不会像 Cloudflare 那样 308）


==========================================================
第六阶段：HTTPS
==========================================================

  优先用服务器现有证书方案（宝塔面板 → 站点 → SSL → Let's Encrypt 申请）
  切勿修改博客的 SSL 配置。

  申请后：
    1. 放开 nginx-mcu-h5.conf 里 HTTPS server 段注释
    2. 填真实证书路径
    3. nginx -t && nginx -s reload
    4. 确认 HTTPS 正常后，再放开 HTTP→HTTPS 的 301 跳转段


==========================================================
第七阶段：完整测试
==========================================================

  页面（全部应 200，无 308）：
    /  /index.html  /next.html  /routes.html  /map.html  /movie.html?id=iron-man
    /next.html?from=iron-man  /routes.html?r=newcomer  /map.html?focus=iron-man

  资源：
    /assets/css/style.css  /assets/js/app.js
    /data/*.js（11 个）  /assets/posters/*.jpg（38 个）
    /assets/stills/*.jpg（38 个）  /assets/miniprogram/qrcode.png

  浏览器 Console 检查项：
    无 404 / 无 JS error / 无 CSS 404 / 无图片 404 / 无 JSON 404
    无 MIME type error / 无 mixed content / 无 CORS error

  功能：
    首页 → 下一部 → 路线 → 宇宙关系 → 电影详情 → 返回
    弹窗、图片、LocalStorage、观影进度、移动端、PC


==========================================================
第八阶段：确认博客不受影响
==========================================================

  curl -I https://你的博客域名.com/        # 应正常 200
  ls -la /www/wwwroot/博客目录/            # 文件时间不应变化
  nginx -T | grep server_name              # 博客 server_name 仍在


==========================================================
阿里云安全组（控制台操作）
==========================================================

  确认已放行：80/tcp、443/tcp
  若已放行（博客在跑，通常是放行的），不要重复添加，也不要动其他端口。
